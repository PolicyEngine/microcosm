# CD source-evidence adapters

This local slice transports and verifies source evidence using invented archives.
It does not admit a genuine candidate, resolve a scientific definition, register
an exposure, read a held-out benchmark, or perform scoring.

The extension adds three terminal artifact-only nodes to the existing 17-node
survey graph. Its ACS node runs the existing Frame-less authenticated source
reader against the original archives, validates the entire source, retains the
original all-source receipt, and exports only the selected lexical view. The new
`microcosm.us.acs_hu_source_projection@1` transport is distinct from the old
prepared-Frame HU artifact. Replaying it produces a bound transport object; it
never mints an authenticated source object or constructs a source Frame.

The current-universe node verifies ASEC source coordinates independently for
each clone role, sorting only the source-coordinate view. It retains the mapping
back to current household positions. Native H_SEQ/cohort and derived source
classifications must agree with the existing source verifier. ACS mapping binds
the full-source receipt used by native origins, exact lexical SERIALNO and the
original member/row evidence. It does not derive NP or source weights from the
current population. Vacancy remains source-side custody without a current row;
unknown tenure and GQ classifications remain separate codes.

The geography node consumes the actual preclone assignment and lookup artifact
edges. It checks clone-pair agreement under seed 0 and the full 436-member
119th-Congress lookup roster. The mandatory materialized verifier separately
compares current geography to the actual original population, so a coherent
change in both clone roles cannot become authority. Person geography follows
the authenticated household membership; household IDs are not native origins.
The sparse fixture does not occupy every district.

The final verifier receives actual executor-observed Population objects, not
declared column projections. It checks every carried cell, order, effective
weight, metadata value, Frame mass log, Population ledger, original design
anchor and owner. Unchanged clones use their original authentic binding. A
later 669 successor must supply its actual opaque enriched-parent and
weight-successor evidence; an origin receipt is never relabeled after
enrichment or calibration. The current tests refuse missing/forged successor
evidence. They do not run a calibration campaign to establish a new positive
successor example.

Private row-level artifacts stay in the graph store, under separate 64 MiB
bounds. The public-facing boundary writes two digest/count/identity summaries
with the actual 821 canonical JSON encoder and its 8 MiB FilePin cap. Factories
close over caller-pinned verifier control/completion/seal files outside the
candidate bundle. Bundle documents cannot supply or override that authority.
An externally pinned control is an execution-evidence input, not a scientific
or action approval.

Only these artifact slots are produced:

- `universe_classification_artifact_id_and_sha256`
- `geography_assignment_artifact_id_and_sha256`

Both definition slots remain unresolved:

- `universe_definition_id_and_sha256_per_block_per_arm`
- `geography_definition_id_and_sha256`

The pure v4 protocol and existing 669/821 sources remain unchanged. The new
modules have their own classified transitive implementation inventory; no
upstream executable inventory is expanded. A preclone geography-reader draft
was rejected because structural dependency closure changed three clone keys.
The terminal three-node design preserves all 17 predecessor keys.

Run the source-owned bounded proof with the pinned Python 3.14.4 executable:

```text
python -I -B -S -X pycache_prefix=<fresh-absolute-absent-path-inside-output>
  tools/cd_source_evidence_proof.py cold --root <fresh-invented-cd-output>
python -I -B -S -X pycache_prefix=<different-fresh-absolute-absent-path>
  tools/cd_source_evidence_proof.py checks --root <same-invented-cd-output>
python -I -B -S -X pycache_prefix=<third-fresh-absolute-absent-path>
  tools/cd_source_evidence_proof.py warm --root <same-invented-cd-output>
```

The bootstrap pins the binary, explicit dependency/source roots, loaded source
bytes and installed dependency versions, and refuses genuine paths,
networking, fitting and policy calculations. Bounds are 120 CPU seconds,
180 wall seconds and 4 GiB RSS per worker. It processes no `.pth` files.
REQUIRED replay uses fatal kernel stubs; setup still reads the invented fixture
declarations and hashes its inputs. Zero kernel calls is not zero parsing.

The source fields and classification definitions are inherited from the pinned
ACS source reader and its [Census 2024 dictionary](https://www2.census.gov/programs-surveys/acs/tech_docs/pums/data_dict/PUMS_Data_Dictionary_2024.pdf).
Source receipt `calibrated_descendants_approved=false` remains immutable. ASEC
interview/cohort versus ACS usual-residence interpretation, a typed GQ reducer
under current calibrated weights, genuine vacancy-exclusion custody, complete
candidate history/approval and empirical national/CD admission remain separate
decisions. B19001, B25003 and the shared occupied-HU total remain reserved.
