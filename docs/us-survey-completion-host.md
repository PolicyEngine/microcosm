# Optional US survey completion host

This source implementation adds opt-in completion to
`run_atomic_survey_financial`. It has not been imported, collected or executed
in this task. Component acceptance does not establish combined-host acceptance.

Select an exact `ChildPropertyOptions` with explicit scenario ID, scope,
`SupportRequirements`, `JointTransport` and keyed stream. Also select
`property_income` and `rebase_property_taxes=True`. `household_roles=True`
requires child completion; its default is `False`. Existing `person_status`
remains independent. Unsupported combinations refuse before source execution.
There are no scientific defaults or new public issuers. The result remains an
existing-issued `AtomicSurveyFinancialRunValues`.

The host first issues and retains the actual property parent (35 nodes, or 39
with status), with tax rebasing disabled. It retains its preparation, source
objects, original legacy/property populations, manifests, store, keys and kernel
registry. Registries are copied before extension. The union executes in the same
store and requires every already-issued parent node to hit cache.

A full-row completion FILTER creates a distinct version. Qualified household
roles optionally add two nodes after incumbent reconciliation. Child completion
adds six nodes, including the generic empirical fit and draw. A separate tax
FILTER, split and gate follow child verification. Tax declarations use the
independently reconstructed completed frame, including its actual role/status
and imputation columns. All three tax nodes bind the actual typed child
verification artifact. The country child verifier owns canonical child evidence;
the tax seam binds its payload hash.

Before compilation, the helper binds exact ordered node identities for receiving1,
optional roles0/2, child6 and tax3. Compensating child/tax count drift refuses even
if the union total is unchanged. The portable child count comes from retained
nodes. Its source-knownness flag comes from the independently reconstructed
child verification bytes that the materialized verifier checks against actual
store evidence; the document retains that same payload's SHA-256.

The private helper independently applies the maintained receiving FILTER and
role reconstruction before constructing `ChildPropertyBoundary`. Its parent
callback returns that same retained Population after pure checks of the issued
base, source ownership, executable closure and complete receiving/role stamps.
Full base/source and role qualification occurs at host boundaries. Ordinary
child borrows do not repeat role parsing. The child fragment itself still
requalifies its source on each `_current()` call.

Both cold execution and required replay load artifacts through the actual
compiled producer, manifest, store, keys and numeric scope. Both invoke the real
child materialized verifier with actual executor-completed output, both actual
support Populations, every actual verification input and the actual verification
output. Required hits skip kernels, so that final verifier is mandatory. Expected
full-population states, receipts, owners, weights and ledgers are compared using
the maintained graph state checker. Final source/store I/O precedes pure seals.
A failed enabled-host check permanently revokes its completion boundary.

Original property verification always receives its original property output.
Status preservation follows the actual FILTER lineage; structural operations
legitimately change inherited owners. Qualified survey reference persons confer
no tax/SPM role, filing status or eligibility. Existing property completion
routing is labeled `pre_child_source_gaps`; those counts are not post-child
completion counts. Public completion metadata is aggregate only.

Only qualified jointly unmeasured eligible children receive paired modeled O/D,
using full original ASEC teenage donors and original household design weights.
Source observations and all nonrecipient/complement cells remain unchanged.
Modeled zero remains `imputed_zero`, distinct from observation. Tax completeness
requires finite nonnegative ordinary interest and dividends for every physical
person, including dependents and zero-weight rows. Unknown adults remain
incomplete and the maintained PUF admission gate must refuse before fitting.
