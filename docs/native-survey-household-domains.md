# Source-owned household domain projection

`qualify_current_survey_household_domains(preparation, allocated_population,
clone_population)` retains a genuine survey preparation and verifies its exact
allocation and ordinary clone0/1 prefix using the maintained no-geography
reconstruction. Its private `QualifiedSurveyHouseholdDomains` capsule provides
`checked_rows()`. Each operation independently rechecks source custody,
implementation, Frame contents, typed weights, original design anchors,
ownership and mass ledger, including an unconditional source epoch close.

The projection joins selected households to authenticated origins by source,
source year, survey year and raw native ID, then to actual assembled support
and spine coordinates. It requires complete one-to-one coverage and exact
rational anchor agreement. Both clone0 and clone1 appear in its immutable
roster. The roster retains institutional and noninstitutional group quarters
as ineligible for the occupied-housing tail stage. Zero mass remains a separate
condition; it does not change source domain classification. ACS and ASEC year
and observation-window distinctions remain explicit.

The small receipt binds the roster digest and counts without repeating private
raw IDs. `roster_rows` counts both clones; `original_households` counts originals.
GQ design anchors are publisher person weights, distinguished by the retained
statistical unit. Neither decoded receipts nor returned rows issue authority. Copies or
manually constructed capsules cannot borrow the original issuer. Changes to
retained source objects, source bytes, implementation, population contents or
metadata revoke the capsule. Final pure source and population checks follow
source-close and code-read callbacks, so a callback cannot replace the baseline
or return an earlier successful result after mutation.

This is a development raw-prefix contract. It has no donor-person allocation,
matching, monetary-placement, geography or release authority. Binding it to a
later pre-geography financial/PUF parent requires a separate receiving-owner
contract with unchanged household lineage. It never promotes an
`InventedHouseholdDomain` declaration to source evidence. Complete-source limits
come from existing admission and roster contracts, not the tiny invented tail
fixtures. This work introduces no calibration targets; poverty stays a
comparison-only diagnostic.

The authored regression suite uses actual source issuers and the real graph
executor over freshly created invented ACS/ASEC bytes. It covers full roster
projection, same-process/store cold/required parity, source and object mutation,
copy refusal, origin join failures, non-prefix refusal and closing callbacks.
This source description is not a test result or actual-source qualification.

The source tests preserve real disk probes, including the maintained full-source
ACS reserve of approximately 17 GiB. The proposed local guardian requires at
least 20 GiB of actual free disk before launch. Running these tests in CI requires
adequate real disk space; a low-disk CI configuration has not been qualified.
