source/native/clone graph and captures actual graph `Population` objects through
the private cold/cache population observer. A complete materialized verifier

`U[o] = min(rD * original prepared DESIGN[o], rI * original incoming IMPORTANCE[o])`.

remains an ancestor and is never relabelled as calibrated evidence.

`GroupedUpperBounds` is the public opt-in constraint passed to `calibrate` and
the private optimizer. Stable household IDs order each group's authoritative

scalar row caps. The reference checker still covers zero rows and can validate
an all-zero group with zero capacity.

Grouped parameters and exponentiation are float64. Both dense and sparse losses
cast only their weight operand differentiably to float32, leaving the constraint
matrix, estimates, and loss scales unchanged. After each update the projection
multiplies the same materialized float64 candidate by one common factor per

close float64 rounding; no tolerance permits an excess. Each accepted vector is
observed, then its logarithm seeds the next internal update. Final storage uses
the exact last accepted observer vector and requires a byte-preserving no-op
projection check, without another exponentiation.
