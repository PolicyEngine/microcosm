# Original survey-arm PUF application

`us_runtime.puf55_original_application` declares all 55 actual conditional
applications per selected original-arm route. It reuses the exact maintained
route fits and consumes the source-qualified, typed fixed-value artifacts.
The fitted-model seed remains the clone-one seed. The caller must choose a
separate, explicit `original_application_seed`; the helper invents no offset.
Existing clone-one declarations and v1 decoders are unchanged.

Every target still draws for every recipient. Its raw draw is retained; the
conditioning output substitutes only cells whose qualified fixed-input mask is
true. Later targets consume that conditioning output. The v2 history binds the
matrix bytes and producer, actual model/conditioning/fixed-input producers,
complete ordered target prefix, raw/conditioning hashes, known counts and the
separate fit/application seeds.

`merge_puf55_original_conditioning` checks the exact closed 55-target routes and
returns a detached tax-unit table and a descriptive receipt. It does not
unpickle models, issue source authority, attach columns, or certify scientific
coverage. Its caller must authenticate each typed artifact against the genuine
compiled graph and retained run, and requalify the original financial/fixed
inputs at the maintained pre/post I/O fences. Merely constructing an
`ArtifactValue` or a matching digest does not satisfy those duties.

Eight shared financial inputs are qualified survey-preserving values; they can
include earlier modeled or split values. Optional pension/IRA/rental/farm fixed
inputs retain the explicit development rules and unresolved source statuses
from `puf55_survey_observed`. None becomes a claim of observed taxability.
An aggregate mask is true only when all members are qualified. A false mask
never permits overwriting known people in a mixed unit.

Population attachment is deliberately separate. This slice does not implement
mixed-unit allocation, pruning, tail caps, tuition allocation, QBI finalization,
a new host entry, or release-science acceptance. Its component proof runs three
real invented-data fits/applications and required replay. Separate synthetic
codec-only 55-target envelopes exercise roster and merger refusal checks;
those envelopes are not evidence of 55 fitted models or a native owner.
