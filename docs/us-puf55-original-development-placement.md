# Original-arm PUF55 development placement

The optional original-arm slice has pure placement helpers and typed graph
fragments. It is not connected to the survey enrichment host. It does not issue
source authority, execute a full PUF55 fit, or qualify a release.

The selected PUF55 profiles contain **52 person outputs and 3 tax-unit outputs**.
The six SCF mortgage-detail fields in the full65 compatibility roster are not
PUF55 targets. The person outputs form three disjoint categories:

- Five possible new singleton values: `long_term_capital_gains_on_collectibles`,
  `non_sch_d_capital_gains`, `partnership_income`, `s_corp_income`, and
  `partnership_self_employment_net_earnings`.
- Twelve qualified fixed values remain unchanged. Eight are survey-preserving
  financial leaves; four use the explicitly recorded development assumptions
  for pension taxability, regular IRA routing, rental proxy, and farm amount.
  These are not newly claimed observed taxable amounts.
- The other 35 person outputs receive no new placement in this slice. This is
  not a claim that all 35 lack existing values.

The three unit outputs are `domestic_production_ald`,
`unrecaptured_section_1250_gain`, and `health_savings_account_ald`.

`puf55_original_placement.placement_result` returns detached full-axis columns
and a descriptive receipt. Its checks require exact ordered entity IDs and
complete memberships, all twelve fixed values known for every original member,
unchanged known person values, and exact fixed conditioning totals. Mixed-known
units remain unresolved. Singleton means exactly one member in the complete
retained person table, not one eligible member or a capped source return size.

A candidate output must be absent in the genuine pre-PUF canonical parent and
introduced by the checked arm-one attachment. Its current owner must still be
that attachment, with original-arm nulls intact. A preexisting column is left
alone even if null. Nullness is an integrity check on authenticated ownership;
it is not source authority, a source NIU-to-zero rule, or legal applicability.
The new values are explicitly modeled development transport. Source knownness
and that transport's scientific acceptance remain distinct.

The pure helper preserves inherited dtypes and requires exact representability
of each new value. Signed outputs are not clipped. A draw outside the maintained
nonnegative domain remains unresolved for that output; no clipping, alignment,
tail cap, multi-person allocation, QBI-support placement, or tuition allocation
is performed. Blocked cells, clone-one values, all other columns and weights are
preserved. Per-output write counts and reasons are descriptive measurements.

`graph_puf55_original_placement.original_placement_nodes` declares a keep-all
version after the supplied current terminal, then explicit full-column rewrite
ownership for the candidate outputs. The attachment consumes every route's
55 model/training/raw-draw/conditioning/v2-state dependencies, plus qualified
fixed inputs and the exact original recipient matrix. Its result helper invokes
the existing strict complete conditioning merger. There is no fabricated
completed prefix or finalizer-only restoration of survey values.
