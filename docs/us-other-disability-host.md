# Other-disability enrichment continuation

`run_us_survey_enrichment` accepts `other_disability_completion=True` with an
explicit nonnegative integer `other_disability_seed`. The default remains
disabled. The existing `n_estimators` controls its quantile forest as well.

The host first completes the requested enrichment fragments and retains their
issued owner, population, terminal artifact, source declarations and kernel
objects. A second graph extends that exact predecessor with the other-disability
fragment. This ordering gives the fragment actual receiving values and terminal
bytes when it declares its dependencies. Every inherited node must hit its
authenticated cache; a node-scoped dispatch guard refuses inherited execution.
The continuation receipt binds that guard's separate policy and implementation.

The disability model always qualifies full original current ASEC donors with
DESIGN weights, independently of `full_original_amount_donors`. It uses current
age, employment income and self-employment income. Known nonreceipt supplies a
zero target. Source-unknown ASEC dollars stay unknown and do not enter fitting.
Original ACS people aged 15 or older receive one draw each, copied to clone arms
0 and 1. Under-15 dollars remain unknown. Source knownness and modeled canonical
knownness have separate columns. The source artifact retains published routing,
allocation and topcode evidence.

A keep-all population version precedes the canonical `disability_benefits`
write. The host compares every carried column, entity axis, weight and inherited
artifact against the retained predecessor. When `original_application_seed` is
also supplied, original PUF placement follows the disability attachment. Its
existing binding observes that real terminal population during graph execution.

Inherited Supplemental Poverty Measure inputs and amount artifacts retain their
source/fragment scope. They do not assert quantities calculated on the final
candidate. Public consumers still receive a checked `SurveyEnrichmentRun` whose
parent is the genuine PUF run. No country engine runs inside this continuation.

The maintained invented test covers the default enrichment terminal, cold and
required replay, source knownness, population conservation and mutation refusal.
Its replay monitor refuses QRF `fit_target` and `apply_target` calls; ancestor
verification can repeat other empirical calculations.
Combined original-arm placement and SPM settings need a separate integration
proof. Actual-data qualification, scientific acceptance, calibration and release
remain pending. Poverty comparisons neither select this model nor gate release.
