# Qualified fixed inputs for PUF55 survey arms

The existing PUF55 recipient interface continues to select clone one by default. `qualify_puf55_survey_recipients(run, arm=0)` adds a separate original-arm projection and distinct graph node IDs. Both projections validate the complete two-arm identity and role mapping. This changes no default application or finalization behavior.

`qualify_puf55_survey_fixed_inputs(run, arm=0)` requalifies the retained financial run and produces the eight current financial targets on the exact person and tax-unit axes. These are **qualified survey-preserving values**: some ACS amounts and component splits are modeled. They are not all raw observations. Tax-unit amounts include every modeled member and are known only when every member is qualified.

The optional `development_rules=DEVELOPMENT_RULES` tuple enables four explicitly provisional ASEC mappings. It preserves the maintained pension fraction, regular-IRA-as-taxable routing, the net-property total as a rental proxy, and the direct farm amount. These require original reporting/amount knownness and exact agreement with the carried person value. NIU, ambiguous zeros, incomplete routing, off-route contradictions and unsupported ACS values remain unknown. A finite inherited column cannot establish knownness. Source totals and unresolved taxable/component-split flags remain in the source-basis artifact. Graph parameters name the assumptions and explicitly say release science is not accepted.

`puf55_survey_fixed_input_nodes(qualified)` declares one artifact-only node for the selected arm. It depends on the genuine source/financial edges, full receiving slices, recipient projection and each selected recipient matrix. Register `Puf55SurveyFixedInputKernel(run, development_rules=...)` alongside the existing recipient kernels. Its outputs include `qualification`, `source_basis`, and the typed target artifacts named by `observed_artifact_names(qualified, profile)`.

Those target artifacts bind exact float64 values, boolean masks, row identities, target names, matrix bytes and the actual matrix producer key. The core `legacy_qrf_apply_observed_matrix_nodes` interface can consume them when the later host integration is enabled. It executes every target model, retains each raw draw, and merges qualified values before subsequent targets. This module does not fabricate an application prefix, fit or apply a model, attach columns, prune records, change weights, or issue a population.

On required replay the host must validate actual producer identities against its complete compiled graph and call `verify_materialized_puf55_fixed_inputs` with the materialized artifacts and matrix edges. The verifier requalifies the real financial and source owners; a receipt, detached dataclass, checkpoint or caller-supplied hash grants no source authority. Whole-host execution, arm placement/finalization, seed policy and scientific release qualification remain separate integration work.
