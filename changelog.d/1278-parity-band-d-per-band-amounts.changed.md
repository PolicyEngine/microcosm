The UK data-target parity register's `local_council_tax_band_d_rate` exclusion now also names the eight per-band amounts, `band_A_amount` to `band_H_amount`, that uk-data#482 adds to `storage/la_council_tax.csv` (microcosm#1278). Each is an English authority's 2026-27 amount for one band (MHCLG Table 9), its Band D amount times the band's statutory ratio. Like Band D, each is a rate, not an additive household control, so none is to be ported as a target. uk-data#482 is open, so the a43e8c5 inventory does not carry it yet; the register is regenerated and a test pins the named columns.
