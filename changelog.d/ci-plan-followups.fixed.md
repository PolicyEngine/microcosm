The CI test plan scopes a file below `tools/` by the whole words of its name, so a pull request that changes only `tools/status.py` now runs the UK engine jobs as well as the US ones, and one that changes only `tools/census_uk_local_targets.py` or one of four other UK tools whose names hold "us" inside another word no longer runs the US engine tests. The US engine runner refuses to start unless its tasks run each file the plan lists for `engine-us` exactly once, and `tools/ci_test_plan.py verify` refuses an `engine-us` group that the runner never runs. A test runs the runner as CI does and reads its exit code. `verify` no longer reads the workflow's job names line by line; `verify-workflow`, which parses the workflow with PyYAML, checks the job set alone.
