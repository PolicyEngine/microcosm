The calibration diagnostics schema's rotated-holdout records now admit the fields the graph's `uk.full.holdout` artifact carries: a skipped holdout's `report_only` flag and `reason`, and on either record the kernel's `graph_binding` to its inputs. The bare `{"skipped": true}` marker remains valid and undeclared fields are still refused. This lets a run resume from its content store after the first K=25 build's terminal-gate refusal without re-keying the stored solve, which the gate kernel's own module would do.
