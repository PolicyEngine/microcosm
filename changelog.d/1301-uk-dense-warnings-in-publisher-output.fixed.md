The release contract's warnings, which the dense UK line's disclosure walk raises without refusing, now reach the publisher's machine-readable output (microcosm#1301, answering the third review of microcosm#1307). `microcosm-publish-release --preflight-only` adds them to its JSON verdict under `contract_warnings`, and a publication lists them the same way beside the pointer it prints; before, they went to stderr only. Each names a file and the paths in it, never a value. `PreparedRelease` carries them as `contract_warnings`, and `publish_release` returns them in the same key without uploading them. When the contract warned, the immutable tag is created with a message recording that the release was published past its warnings and how many there were, but not the warnings themselves. Neither path refuses on a warning or asks for an acknowledgement: the walk warns and never refuses.
