`tools/certify_uk_cut_in_policyengine_py.py` certifies a published UK cut into policyengine.py on a fresh branch: it refuses when another pull request or branch is already certifying the cut, checks the regional route before writing anything, runs certify-data, the lock, TRO, constant and snapshot regeneration and the strict bundle check, measures the UC floor and runs the tests, then drafts the pull request with every judgment call left as a checklist. An accepted regional model mismatch certifies with policyengine.py's audited input-surface evidence (policyengine.py#699). Its load limit, commit co-authors and pull request footer are the operator's to set.
