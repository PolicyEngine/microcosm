US post-export scoring computes the baseline for all five post-export stages (the reform-coverage smoke, reform validation, demographics and the SSI/Social Security and Medicare IRMAA held-out reports) in one pass over the written H5's household batches, instead of one pass per stage: 177 batch engines instead of 885 on a national export. Each stage still receives only the keys its recorded plan holds, and the values are byte-identical. If the shared pass raises, every stage runs its own pass as before. Reform validation scores the pre-OBBBA state once for both OBBBA groups (income tax and estate tax in 2026), so its recorded `reform_passes` and `reform_systems` in the manifests' `post_export_scoring` block drop from 54 to 53 while `reform_validation.json` is unchanged; `tools/probe_us_post_export.py`'s plan comparison against a release built before this change therefore reports reform validation's 53 against 54. The guard sweep tool's baseline worker uses the shared pass too (microcosm#1595).
