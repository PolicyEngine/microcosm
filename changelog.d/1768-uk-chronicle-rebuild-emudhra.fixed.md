The UK Chronicle rebuild's Modal image (`tools/modal_rebuild_uk_chronicle_artifact.py`) stops trusting emSign ECC Root CA - G3, the eMudhra CA certificate removed after the 2026-10-20 key disclosure, as the US Modal image does (`emudhra-ca-trust.fixed.md`). Before any other download it upgrades `ca-certificates` and replaces the cached `debian_slim` base's pip 25.3 with a hash-pinned pip 26.2.2; it then installs uv 0.13.4 instead of 0.11.7 and requires certifi 2026.10.19 or later beside `huggingface_hub`. So neither the packages an upload runs with `HF_TOKEN` nor the upload's connection to the Hub depends on that root. uv 0.13.4 installs Python 3.14.8 for the rebuild, where uv 0.11.7 installed 3.14.4.
