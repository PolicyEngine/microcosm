`microcosm.build.build_folder_switch` can now move the US builds still in use (microcosm#1560). Its `copy` step also copies the files in a build's tagged folder that its checksum ledger records but its release manifest doesn't declare, as each US ACS local-area build has, after checking each against the ledger's SHA-256, and leaves them undeclared; and a release manifest that declares its own `build_manifest.json`, as the US SPM builds' do, now declares the rewritten build manifest by its new SHA-256 instead of being refused. Its `switch` step takes `--finished-branch BRANCH` for a `release-staging/` branch that a finished publication left behind: it accepts the branch while a tag of its build exists and the commit it names is on `main`, leaves it in place, and refuses if it moves before the switch commit; every other staging branch is still refused, and the refusal now names the option.
