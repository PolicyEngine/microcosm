The US release's engine-free post-export dry run now returns every request each post-export stage makes as a picklable `PostExportRequest` (`microcosm.build.us_runtime.post_export_requests`): the stage, the request's place in the order the serial scorer runs it, the variable, period and `map_to`, and for a reform request the description its reform is rebuilt from (the smoke probe, the reform-validation spec, or a cumulative OBBBA state's parameter changes) and which of the stage's reformed simulations asked for it. Reform validation, like the smoke check, now hands the dry run those descriptions instead of building reforms, so the dry run needs no policyengine-core, and it refuses a reform it cannot describe or pickle. Nothing records the descriptors: the plan in `calibration_diagnostics.json`, each stage's output and each stage's reform-pass count stay the same, which a test pins on a fixture. `RECORDS_REQUESTS_ONLY` moves from `reform_coverage_smoke` to the new module. `tools/sweep_us_post_export_scoring.py` records through the descriptors and rebuilds each reform in the worker that scores it.
