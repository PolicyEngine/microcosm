The UK spine build now reports all of its work after the graph run inside stages, so the staging dashboard's build timeline has no unexplained empty stretches. A new `graph_evidence_capture` stage covers saving the graph manifest, schema and run evidence and reading the stored stage artifacts back, which previously ran before the first stage update after the graph. With `--checkpoint-dir`, a new `checkpoint_h5_creation` stage covers the checkpoint, whose completed event carries its `sha256` and `size_bytes`. `sidecar_creation` now also covers the HMRC replay sidecar. The checkpoint `frs_spine.h5` is now a byte copy of the finished output instead of a second serialization of the frame: it has the digest the build sidecar records as `output.sha256` and, on a smoke build, keeps the non-release marking.
