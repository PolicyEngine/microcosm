The calibration-diagnostics schema-8 JSON Schema is committed at `packages/microcosm-diagnostics/src/microcosm/diagnostics/schemas/calibration_diagnostics.v8.schema.json` and ships in the `microcosm-diagnostics` wheel (microcosm#1293). `tools/generate_calibration_diagnostics_json_schema.py` regenerates it, and `--check` reports a stale file. A byte-exact drift test keeps the file equal to freshly generated output. In their engine-free tests, the US national release writer, the ACS local-area calibrate stage, the UK writer, the UK graph terminal gate kernel and the transport terminal kernel now validate the diagnostics they write against the committed file.
