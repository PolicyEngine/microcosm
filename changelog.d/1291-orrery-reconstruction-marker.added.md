Add `microcosm.graph.reconstruction`, which rebuilds a declaration-only graph schema from a build's recorded `graph.json` and marks it with the `microcosm.reconstruction` extension (protocol `microcosm.graph.reconstruction.v1`). The marker names the revision that declared the graph (`source_revision`), the revision of the code that performed the reconstruction (`reconstruction_revision`, read by `code_revision` from the checkout that tracks that code), and every input file by digest. Only the declaration's bytes come from the build: the schema's `compiled`, `fields` and `input_bindings` sections and the Orrery projection come from the reconstructing code. The marker travels in `graph.schema.json` into the Orrery document's metadata. A declaration that the current serializer would not reproduce byte for byte is refused, and no operation is presented as executed.
