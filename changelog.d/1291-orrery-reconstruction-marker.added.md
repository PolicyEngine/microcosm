Add `microcosm.graph.reconstruction`, which rebuilds a declaration-only graph schema from a build's recorded `graph.json` and marks it with the `microcosm.reconstruction` extension (protocol `microcosm.graph.reconstruction.v1`). The marker names the source revision and every input file by digest, and it travels in `graph.schema.json` into the Orrery document's metadata. A declaration that the current serializer would not reproduce byte for byte is refused, and no operation is presented as executed.
