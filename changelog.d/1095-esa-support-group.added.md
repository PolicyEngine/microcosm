The UK root stage sets `esa_includes_support_component` from the FRS ESA group, which the benefits tab records on each ESA row (BENEFIT 16) as VAR3, ESAGROUP: 1 the work-related activity group, 2 the support group, 3 the assessment phase, as the FRS 2024-25 variable listing formats the questionnaire's ESAGroup (UK Data Service SN 9563, sheet BENEFITS_table; microcosm#1095). policyengine-uk reads the input since 2.129.0 for the benefit cap's ESA exemption and Universal Credit's test of limited capability for work-related activity, and without it assumes the support group for anyone with an ESA award of their own. A stored column replaces that default for everyone, so the column is false only where a person's ESA rows record a group outside the support group and none records it, and true everywhere else; a benefits tab without VAR3 refuses. On SPI-redrawn rows, whose ESA receipts the stage-2 fill takes from other FRS donors, the column returns to true. It is a net-new export column, so it joins the reviewed extra columns of the export-surface gate. The release reports the column only as support group against not support group: the assessment-phase answers are too few to report on their own.
