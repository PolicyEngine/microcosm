Stop trusting the compromised eMudhra (emSign) CA certificates, whose intermediate private keys were disclosed on 2026-10-20 (https://emudhra.we-have-a-problem.com). The lock moves certifi from 2026.5.20 to 2026.10.19, the first certifi release without emSign ECC Root CA - G3; nothing else in the lock moves, and `APPROVED_UV_LOCK_SHA256` is re-pinned for the new lock. The Modal stage image (`tools/modal_us_stage.py`) installs uv 0.13.4 instead of 0.11.7, because uv verifies HTTPS against a CA list compiled into it; requires certifi 2026.10.19 or later beside the runner's `huggingface_hub`; and upgrades `ca-certificates` to Debian's current release, which git and the stdlib's ssl module read.
