Signed register entries are checked with one shared review core (microcosm#1759). `microcosm.build.declared_registers` gains `read_strict_json`, `canonical_date`, `ReviewWindow` and `stale_entries`; they return values, and each country's code keeps its texts and decides what a lapse does. The UK calibration measure exclusions and the support floor (`uk_runtime.measure_simulation`, `uk_runtime.support_floor`) read their dates and windows with it. No result, warning, error class or error text changes: `test_uk_review_loaders.py` holds the new code to verbatim copies of the old functions on the packaged file, on changed copies and on the days around each window edge. The UK target and national kernels now also hash `declared_registers`. The small-cell deferrals keep their own expiry check: it also accepts compact dates, so moving it would change what it accepts. The UK reviewed-exclusion registers (target fit, local target fit and area support, in `uk_runtime.weighted_integrity`) read their files with `read_strict_json` and their dates and windows with `canonical_date` and `ReviewWindow` (`UKReviewedExclusion.window()` is new); `test_uk_reviewed_exclusions_core.py` holds them to verbatim copies of the old reader, date checks and window methods, by error class and text (a gate that fails closed records the class name, so the reader still raises a plain `ValueError`). The UK gate kernels that read these registers now also hash `declared_registers`.
