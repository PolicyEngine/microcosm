UK builds now name their build for the collector when they hand their staged dataset bundle to the emitter, and so does the re-stage command (`tools/stage_uk_rowwise_candidate.py`), copied-back Modal runs included. The hand-over carries the interface's `CollectorProvenance`: country `UK`, the build's attempt ID (which a release build keeps as its folder name, whatever run ID the staging used), licensed data, and the release the build is a candidate for, from the manifest's `release_id` (`microcosm-uk-2024-25-national` or `-dense`, otherwise none). The emitter submits the bundle's calibration diagnostics to the collector from it once the bundle's commit lands, but only while its collector submissions are on, and no emitter release Microcosm accepts can switch them on yet: until one can, the bundle goes to Hugging Face alone. Submissions at release need an emitter release whose release publication carries the same provenance.
