Bind a US replacement-scorecard row's area identifier to the level and declaration that resolved it. The national/state/congressional-district view chose a level from one piece of evidence and then searched an ordered metadata key list that consulted neither, so a row without a view-level hierarchy id would have reported the parent `state_fips` the target compiler derives from a district geoid, or a sub-state hierarchy id as a state's. That search was unreachable for every spec the US compiler can currently emit -- each carries a hierarchy whose geography id is non-empty -- so no scorecard's counts change; this closes the hole before a producer reaches it. An identifier is now read only from a declaration at the row's own level, a row with none keeps an empty identifier, and the artifact reports which declaration named each area. Distinct-area counts are taken over census GEOIDs alone, with bare-form and unidentified rows counted beside them, so one area cannot be counted twice under two spellings. Scorecard schema 4 -> 5.
