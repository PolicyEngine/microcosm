The US base build produces `employer_sponsored_insurance_premiums` (microcosm #454). The `meps_esi_premiums` stage, declared but unable to run because the pinned ASEC inputs lack the Census policyholder fields, now reads `NOW_OWNGRP`, `NOW_HIPAID`, `NOW_GRPFTYP2`, `PEMLR` and `NOEMP` restored from the pinned Census person files. Every current ESI policyholder takes the MEPS-IC 2025 employer share for their coverage tier, firm size and State (census division for government employers), and one factor scales that whole universe to CMS NHE Table 24's employer contribution ($1,047.0B for 2024), which counts active employees, COBRA enrollees and retirees. The column carries the employed policyholders' part ($925.7B on the default pool, before calibration); dependents, non-employed policyholders and the unincorporated self-employed carry zero. A release must now carry the input with signal and its raw ASEC coverage columns, and hold the anchor-universe total within 5% of the anchor on the dense and the sparse export; the verdict ships as the `esi_premiums` gate evidence. The multispine pool does not run the stage yet, and an ACS local build refuses a frame whose input is null on its ACS rows. `pre_tax_health_insurance_premiums` is not produced: it waits for the engine's disjoint premium contract (policyengine-us #10046).
