  - On that definition it re-derives each household's fallback level from its stored draw inputs (`uk_draw_inputs`, `uk_draw_levels`, `uk_draw_frame`) and runs the shared validation (`atomic_geography.validate_geography`) on the stored assignment and ladder columns, as the area draw checks the rows it places.
