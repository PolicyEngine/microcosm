`python -m microcosm.build.uk_runtime.orrery_reconstruction` now writes only the reconstructed `graph.schema.json`, which carries the reconstruction marker, and its report; it no longer projects `graph.orrery.json` or writes `orrery.upload.json`. The collector's projection keeps the marker, so a document made from the schema shows it. The report's protocol is now `microcosm.uk.orrery-reconstruction-report.v2`: `publication_id` and `published_files` are gone, and `files` lists what the command wrote. A build that records Orrery evidence is refused with a pointer to `python -m microcosm.build.uk_runtime.orrery_inputs`. The Python function is now `reconstruct_uk_schema`.
