The FRS spine refuses a region (GVTREGNO), tenure (PTENTYP2) or accommodation (TYPEACC) code outside the FRS data dictionary, and names the variable, where it used to map the code silently to a default (uk-data#636, microcosm#1095). A blank value keeps its default, as before: some FRS 2024-25 households leave TYPEACC blank, and they stay detached houses, as uk-data#636 maps them. Every code on the FRS 2023-24 and 2024-25 household tabs is in the dictionary, so the spine does not change.
