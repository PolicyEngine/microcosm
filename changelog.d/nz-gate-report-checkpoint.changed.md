New Zealand's entitlement declaration adds `nz.gates.terminal` to its checkpoints (ruling d3058), so a run keeps the manifest of the terminal gate closure (the calibration diagnostics, the six evidence nodes and the battery) when `export.prepare` refuses on a blocking gate report. No gate changes, and no node key moves. A run now writes three extension checkpoint manifests instead of two. The cell diagnostics collector feeds the terminal battery, so it now executes inside the `nz.gates.terminal` checkpoint, and the third manifest records it from the store. One trade-off follows: if the calibration diagnostics or one of the six evidence nodes raises, the run stops before the collector runs, and the cell diagnostics manifest that the old order kept is not written.
