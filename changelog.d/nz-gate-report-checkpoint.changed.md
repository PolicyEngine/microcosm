New Zealand's entitlement declaration adds `nz.gates.terminal` to its checkpoints (ruling d3058), so a run keeps the manifest of the terminal gate closure when `export.prepare` refuses on a blocking gate report. That manifest includes the calibration diagnostics, six evidence nodes and the battery, which no earlier checkpoint records. No gate changes, and no node key moves. A run now writes three extension checkpoint manifests instead of two. The cell diagnostics collector feeds the terminal battery, so it now executes inside the `nz.gates.terminal` checkpoint, and the third manifest records it from the store. One trade-off follows: if the calibration diagnostics or one of those six evidence nodes raises, the run stops before the collector runs, and the cell diagnostics manifest that the old order kept is not written.
