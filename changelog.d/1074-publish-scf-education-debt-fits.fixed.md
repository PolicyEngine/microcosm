A `--scf-education-debt` release now publishes its two SCF education-debt fit tables, `us_scf_education_debt_fit.json` (at the pre-calibration weights) and `us_scf_education_debt_calibrated_fit.json` (at the shipped weights). The release tool writes both into the release directory, not the artifacts directory, and the release manifest lists them as `diagnostics` artifacts, so the publisher uploads them under `releases/<id>/` without `--extra-file`. Before, the manifest listed neither, so a publish left both on the run host. A build without the flag writes and lists neither, and a flagged build missing either table fails before it writes a manifest (#1074).
