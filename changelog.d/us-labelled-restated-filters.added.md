The US fiscal materializer now accepts a Ledger filter key that restates a constraint it already applies — a labelled feed's `ledger_filter_us:statutes/26/62#adjusted_gross_income_lower_bound` beside the compiled `agi_lower_bound`, or a qualifying-child bound beside `ledger_filter_eitc_child_count` — but only on specs where the restatement and the applied filter select the same population. A restatement that disagrees, or that has no compiled counterpart, keeps the existing refusal and now names both values, and the SOI slice's silent skip honours the same rule so an accepted restatement cannot drop a target without an error.
