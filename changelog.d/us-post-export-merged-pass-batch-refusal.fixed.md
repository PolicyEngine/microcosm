US post-export scoring's merged baseline pass now raises a refused household batch file, one whose bytes changed or that cannot be read, at once, so certification stops there. Before, it caught that error like any other, printed that each stage would score its own baseline plan, and the first stage's own pass read the same file again. A file whose bytes changed raised the same error one pass later. A read error that did not happen again on that second read let certification go on; it now stops certification, as a refused batch file does in every other post-export stage. Scored values are unchanged whenever certification completes.
