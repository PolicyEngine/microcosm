Every build now checks columns that frames share. Frame operations record a SHA-256 digest of each column when they start sharing it. The `Frame` constructor, `engine_tables`, and checkpoint and output writers compare the digests first, and raise `SharedColumnChangedError` naming each table and column whose shared memory was changed in place. `Frame.replace_tables` and `Frame.with_columns` also compare each recorded column they drop or replace before building the new frame, so a changed column cannot leave unreported while a column derived from it carries the change on.
