`--inspection-export` describes its export again (#931). The inspection kernel (`inspection_export.UKInspectionExportPrepareKernel`) called `graph_terminal.describe_uk_export` without the solve year that function requires, so a dense build with `--inspection-export` failed with a `TypeError` at the export description. The kernel now passes the export node's `solve_year`, as the export kernel does. The kernel's test stands in for the description with an autospec of the real function, so a call that leaves out an argument it requires fails there as well. Only the inspection kernel's hash moves; no other node key, declaration or generated file changes.
