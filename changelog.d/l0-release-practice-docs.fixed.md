DESIGN.md, the README's package table and the US release build rule now say what `calibrate()` and the US releases do. `calibrate()` sets no weight to zero unless a caller passes a positive `l0_lambda` or any `target_records`, or chooses `method="prox"`. It accepts `method="apg"` only as a deprecated alias for Adam. As of 2026-11-15, every US national calibration that PolicyEngine had tagged in `policyengine/populace-us` since 2026-07-01 came from the US builder's `--dense-default-dataset` arm, and their build manifests record `dataset.default.method: dense_no_l0`. The builder's help for `--dense-default-dataset`, `--l0-refit-lambda-share`, `--refit-l2-lambda` and `--epochs` now says what each flag does and no longer calls the dense arm diagnostic only. This changes no flag, default, calibration or dataset.
