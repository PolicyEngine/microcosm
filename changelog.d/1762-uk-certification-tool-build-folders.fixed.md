`tools/certify_uk_cut_in_policyengine_py.py` certifies a UK build published into its own folder. It takes the national build by name (`--national-build`) and a local-area build the same way (`--dense-build`), refuses a build that `releases.json` at `main` does not list or has withdrawn, pins each build at the commit that published its folder (or a commit in `main`'s history named with `--national-data-commit` or `--dense-data-commit`), and hands policyengine.py's `certify-data` each build's folder manifest at that commit. `--keep-regional-release` reads the kept local-area build at the folder and commit the bundle pins, the regional microdata is read from the build's folder, and the certified-constant rewrite moves the local-area build's commit as well as its name. A Hub failure is a refusal, a policyengine.py base that cannot read build folders (policyengine.py#683) is refused before anything is downloaded, and a resumed worktree that pins another national commit or regional route is refused. Tags (`--national-tag`, `--dense-tag`) are no longer accepted, since policyengine.py refuses a tagged manifest from a repository with `releases.json`.
