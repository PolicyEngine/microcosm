microcosm-fit now refuses invalid input that it used to accept silently or crash on. The microimpute bug-parity audit reproduced each case against microcosm-fit. Every valid input fits, draws and scores exactly as before: a differential run of one fixed workload through the old and new code matched in every value. Only the attested kernel hashes move, because the fit kernels' source bytes changed.

- `RegimeGatedQRF` and `CategoricalClassifier` refuse a boolean or non-integer seed at construction, and `RegimeGatedQRF` also refuses a negative seed and a boolean or non-integer `n_estimators` there. Before, `RegimeGatedQRF` turned `seed=True` and `seed=1.9` into seed 1, so two different seeds shared one random stream, and `CategoricalClassifier` did the same with `seed=True`.
- `RegimeGatedQRF`, `detect_regime` and a loaded chain checkpoint (`QRFChainState`) require a finite, non-negative `zero_atol`. Before, a NaN or infinite tolerance made a positive target fit as degenerate zero and draw only zeros.
- A DataFrame fit refuses a predictor, target, weight or groups label that names more than one column. Before, the fit read the label as a two-column frame without saying so, and in the audit's repro a duplicated target fit as degenerate zero.
- `categorical_scores` requires each row of `proba` to be a probability distribution over `classes`, the classes to be distinct, the weights to be finite and non-negative with a positive total, and each stratum to label every row. It maps each label to its column by the order of `classes`, so unsorted classes now score instead of failing with "Every label must be one of classes". Before, probabilities of `[[2, 0], [0, 2]]` scored a log loss of -0.69, negative weights scored, and NaN or all-zero weights scored NaN.
- A weighted fit refuses, by name, a target whose positive or negative donor rows all carry zero weight. Before, the weighted bootstrap failed with "Probabilities contain NaN".
- A fit refuses an empty training table. Before, it fit the target as degenerate zero and predicted zeros.
- A gated model answers an empty recipient batch with an empty result in `predict`, `conditional_uniforms` and the chain step, positional or keyed, as `predict_from_uniforms` already did, and `predict` consumes no draws for it. Before, the sign gate's classifier refused the zero rows.
- `donor_distance_features` refuses a missing or non-finite rank or presence-rank value and a missing categorical value. Its new `unseen_categories` argument sets what happens to a recipient category that no donor holds: `"refuse"`, the default, raises, and `"ignore"` keeps the old all-zero indicators. Before, a missing recipient rank value ranked as the largest, a missing presence-rank value counted as absent, and an unseen category became an all-zero dummy without a word.
