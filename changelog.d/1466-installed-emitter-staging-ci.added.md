A new CI job, `installed-emitter`, stages bundles through the released `microcosm-emitter`: `tools/run_installed_emitter_tests.sh` installs it at `MINIMUM_EMITTER_VERSION` and at the newest release pinned in `tools/installed-emitter/requirements.txt`, each into its own uv tool directory, and runs the new `installed_emitter/shared/` tests once for each. The tests start the installed command with `start_bundle_emitter()` and send its Hugging Face Hub requests to a loopback stand-in Hub server (`test_support/microcosm_build/stand_in_hub.py`) through `HF_ENDPOINT`, so the job needs no secret. They cover an upload in one commit and the files `copied_files` lets the build rewrite, a bundle staged again (`already_staged`), a read-only credential and a refused commit (`UPLOAD_FAILED`), a Hub that never answers (`UPLOAD_PENDING`, then the re-stage's record), and the minimum-version check.
