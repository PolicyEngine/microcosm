A new CI job, `installed-emitter`, stages bundles through the released `microcosm-emitter`: `tools/run_installed_emitter_tests.sh` installs it at each release `tools/installed_emitter_releases.py` names (`MINIMUM_EMITTER_VERSION`, then the newest release pinned in `tools/installed-emitter/requirements.txt`), each into its own uv tool directory, runs the new `installed_emitter/shared/` tests once for each, and warns when the package index has a newer emitter release than the pin, or a newer `huggingface-hub` 1.x release than the one the stand-in models. The tests start the installed command with `start_bundle_emitter()` and send its Hugging Face Hub requests to a loopback stand-in Hub server (`test_support/microcosm_build/stand_in_hub.py`) through `HF_ENDPOINT`, so the job needs no secret; with Xet off, the dataset travels through the LFS upload a real Hub requires. They cover an upload in one commit on the head it names and the files `copied_files` lets the build rewrite, a commit refused for an older head and made again, a bundle staged again (`already_staged`), a read-only, rejected or missing token, a refused commit (`UPLOAD_FAILED`), a Hub that never answers (`UPLOAD_PENDING`, then the re-stage's record), and the minimum-version check.
