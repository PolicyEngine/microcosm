Add `tools/check_uk_itl_projections.py` and `microcosm.build.uk_runtime.itl_differential`, a standing check of a calibrated UK file against HMRC's Income Tax liabilities statistics (July 2026) projections at the calendar-2025 window: Income Tax payers by total-income band and in all bands (Table 2.5), of State Pension age and aged 65 and over in the United Kingdom (Table 2.1) and in each of the twelve region-tier areas (Table 2.2), and below State Pension age. It reads the vendored `hmrc_itl_taxpayer_counts.json`, gives each cell its model count, relative miss and a tolerance fixed before any file is read (5% national, 10% regional), and marks a cell in sample when a bound target reads it: from the run's `calibration_diagnostics.json`, or else the contract, which binds Table 2.5's bands and, since microcosm#1069, Table 2.2's areas. A sum of cells is in sample only when every part is and the file holds nobody it counts outside them. It is a check, not a target: nothing feeds calibration. Ported from the closed pilot PR microcosm#1413 without its dated SPI path.
