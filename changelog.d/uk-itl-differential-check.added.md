Add `tools/check_uk_itl_projections.py` and `microcosm.build.uk_runtime.itl_differential`, a check to run on a calibrated UK file against HMRC's Income Tax liabilities statistics (July 2026) projections at the calendar-2025 window: Income Tax payers by total-income band and in all bands (Table 2.5), of State Pension age and aged 65 and over in the United Kingdom (Table 2.1) and in each of the twelve region-tier areas (Table 2.2), and below State Pension age. It reads the vendored `hmrc_itl_taxpayer_counts.json` and gives each cell its model count, its relative miss and a tolerance fixed before any file is read (5% national, 10% regional). It marks a cell in sample when a bound target reads it. The basis is the run's `calibration_diagnostics.json`, or else this tree's target references at the check's year, which bind Table 2.5's bands and, since microcosm#1069, Table 2.2's areas. A cell made of others (a sum, or the count below State Pension age as a difference) is in sample only when every part is and the file holds nobody it counts outside them. With the diagnostics, each bound cell also shows the run's own estimate of its target beside the model count, as a count difference and, when the estimate is above zero, a relative one. It is a check, not a target: nothing feeds calibration, and nothing runs it automatically. Ported from the closed pilot PR microcosm#1413 without its dated SPI path.
