The US ACS local release's Census population targets label each state and congressional district the way the release's other targets label the same id (microcosm#1335). The release `populace-us-2024-buildo-acs-local-766b7c7-20261017T030317Z` labelled each of its 51 states with its Census name on the IRS SOI, SNAP and Medicaid targets ("Maine") and with its postal code on the state population target ("ME").

- **States.** A population target's state label is the state's Census name from the new shared table `microcosm.calibrate.geography_constants.US_STATE_FIPS_TO_NAME`. Its 51 names equal the release's ledger state labels and the names every Chronicle source package of the pinned US feed declares. The block ladder's `US_STATES` table now derives its P.L. 94-171 directory names from it (the derived table equals the previous literal).
- **Congressional districts.** A district's label is the Census Bureau's name ("Congressional District 1 (119th Congress), Alabama", "Congressional District (at Large) (119th Congress), Alaska", "Delegate District (at Large) (119th Congress), District of Columbia"), from `congressional_district_label` in `microcosm.build.us_runtime.congressional_district_vintage`. The IRS SOI district rows translated to the 119th Congress plan take their label from the same function. The two producers used to disagree on at-large districts ("AK at-large congressional district" against "AK congressional at-large"), so a surface binding both at one at-large id gave it two labels. A feed with Chronicle's ACS district facts, which carry the Census names, now agrees with both.
