`UK_ENGINE_DEFAULT_INPUTS` (`microcosm.frame.adapters.policyengine_uk_concepts`) signs the engine inputs the UK build leaves at policyengine-uk's default as approximations, each with the error it can make (microcosm#1095). Its first entry is `self_employment_gross_receipts`: no source of the self-employed's turnover is read yet, so `trading_allowance_deduction` relieves a profit of £1,000 or less in full and gives a larger profit no allowance, which puts taxable profit at most £1,000 a person from where receipts would put it. Tests check that each entry is an engine input the mapping never binds and that no spine column writes it.
