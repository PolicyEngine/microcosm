The NZ geography assignment test (microcosm#1732) now checks each derived layer, and each person's region, against support-column maps the test states itself, and checks each support row against its builders: its area code, population code, target and alternate AS area. It composes the geography nodes on the assignment's population and the `nz.open` boundary filter as `compose_transport_graph` does and runs them through the graph executor. Stand-ins replace only `nz.create`, which gives CREATE's real columns and dtypes, and the target surface, which holds the support references in `nz.facts.precal`'s `references` parameter, with synthetic counts. So the boundary, support, assignment, derivation, person location and gate kernels run with the executor's own projection and result checks.
