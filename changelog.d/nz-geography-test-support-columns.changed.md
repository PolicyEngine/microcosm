The NZ geography assignment test (microcosm#1732) now checks each derived layer against a support-column map the test states itself. It composes the `nz.geo.*` nodes as `compose_transport_graph` does, takes the support system and alias from them, and runs each node's declared kernel on the household table the graph executor would give it, with the executor's check that a kernel returns exactly its owned columns, each declared as produced on every household.
