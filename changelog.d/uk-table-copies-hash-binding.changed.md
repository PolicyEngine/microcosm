The UK stage, population and calibration kernels' implementation hashes now include `microcosm.frame.table_copies`, which `_minimal_frame` and the UK `context_frame` copy each kernel's inputs with (#1746). `source_hash` reads only the modules it is given, so before this an edit to `copy_table` left those kernels' node keys unchanged, and a graph store built before the edit could serve their nodes. The hashes move once more with this change: the next UK spine or full build reruns those nodes and every node after them, because a node key is derived from the keys of the nodes that produced its inputs. No data output changes.
