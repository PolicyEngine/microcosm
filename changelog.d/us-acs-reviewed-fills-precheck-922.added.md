`tools/check_us_acs_local_reviewed_fills.py` grades a staging summary's reviewed engine-input nulls against the ACS local release's fill rules in seconds, before the release runs (microcosm#922). It refuses what materialize would refuse (a null in a never-default-filled column off the ACS spine, a null ESI premium), builds the fill records the release would write with the engine defaults the release resolves, and runs the release's own finalize gate (`acs_local_reviewed_fill_consumer_gate`) on them, which otherwise refuses an unregistered fill hours into the run. It exits 2 when the release would refuse.
