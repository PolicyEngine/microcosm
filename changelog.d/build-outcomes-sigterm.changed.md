UK spine, dense and national builds now record a SIGTERM (a supervisor, a budget stop, `kill`) instead of dying silently: the staging run closes `failed` with `TERMINATED`, the attempt gets a `discarded` Logbook row like Ctrl-C, and the command exits with status 143. The spine build now also records Ctrl-C (it used to leave the run `running` with no row). A second SIGTERM still kills the process at once; SIGKILL and out-of-memory kills stay covered only by the hosted emitter's heartbeat.
