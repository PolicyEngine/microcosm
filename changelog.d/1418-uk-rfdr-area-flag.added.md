The dense build now sets policyengine-uk's `in_rural_fuel_duty_relief_area` on each placed household from its assigned output area, so the Rural Fuel Duty Relief prices its petrol and diesel at the relieved rate (#1418). HMRC Notice 2001 opens the relief in the Inner and Outer Hebrides, the Northern Isles, the Islands in the Clyde, the Isles of Scilly, the post town of Hawes and sixteen mainland postcode districts. It names the island groups without bounding them, so `tools/build_uk_rfdr_area_layer.py` declares Microcosm's translation into postcode districts and sectors, with sources. It then reads the ONS postcode lookup and writes `uk/rfdr_area_layer.json`, the 2021 output areas of England and Wales and 2022 output areas of Scotland more than half of whose postcodes lie in the scheme. That is 41 in England and 1,053 in Scotland, from 7,104 postcodes of the August 2026 lookup. Islands that share a sector with the mainland (Raasay, Seil, Easdale, Luing, Kerrera and Lismore) and the post town of Hawes are listed by unit postcode. The post-geography node `uk.full.geography.rfdr` (`--rfdr-localisation area`, the default with the atomic assignment; `none`, the default with the legacy assignment, is for measurement builds and refused by a release candidate) reads it. Northern Ireland has no area in the scheme. The national line, which has no areas, leaves the engine's default of false (María's ruling of 2026-10-28). The node refuses a Great Britain output-area code that is not well-formed for its system. On a full-scale build it also refuses a system (England and Wales, or Scotland) with households none of which is flagged, so a change of code format or vintage cannot publish its households unflagged; a sampled rung may place none of the 41 English areas, so it checks the codes only. The committed layer is built from the NSPL zip Chronicle registers. The tool pins the registration's package id, file and sha256, and `--check` rebuilds the layer in memory and compares it with the committed files. A test holds the provenance to the high value home stock's own record of the zip.
