The ACS local-area release's package stage now refuses to give a build an ID that names code other than the code that wrote its calibrated artifact. Calibrate reads its code identity when the stage starts and records it in `consumer_export.json`; it refuses to write the artifact if the checkout's commit or dirty state changed before the write. Package requires the same commit, and counts a writer record that does not say its tree was clean as dirty. The interim WIC limitation now states exactly whom the assumption covers, and its receipt records how many people were allowed to lack a decision.
