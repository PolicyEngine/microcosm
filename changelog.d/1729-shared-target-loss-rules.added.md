Add shared target-loss rules (`microcosm.calibrate.target_loss_rules`): a loss weight and a loss cap for each target from its level, family, value basis and value, with the rule declared by name and parameters. Both countries now compute their loss weights with them, with the same vectors as before, bit for bit: the US formula is the shared rule `sqrt_value_concept_budget`; the UK local rules (`uk_runtime.target_weights`) are `uniform`, `level_equal` and `level_family_equal`, and the UK national `family_equal` (`uk_runtime.national_doctrine`) is `level_equal`. Each country declares its rule names as shared rules. The ACS local release takes `--target-weight-rule` (default: the formula every build has used). The UK problem, national and rotated-holdout kernels hash the shared module, so those UK nodes re-key (microcosm#1729).
