Add shared target-loss rules (`microcosm.calibrate.target_loss_rules`): a loss weight and a loss cap for each target from its level, family, value basis and value, with the rule declared by name and parameters. The US loss-weight formula is now the shared rule `sqrt_value_concept_budget` (same weights, bit for bit), the ACS local release takes `--target-weight-rule` (default: the formula every build has used), and `uk_runtime.target_weight_declarations` states each UK rule as a shared rule and is held equal to the UK code by test; the UK solve does not read it yet (microcosm#1729).
