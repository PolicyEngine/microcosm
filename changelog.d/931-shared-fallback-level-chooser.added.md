A country-neutral fallback-level chooser for conditioned area draws: `FallbackLevel` and `choose_fallback_levels` in `microcosm.build.atomic_support_conditioning` (#931; shared, for Max's review). The shared draw (`assign_atomic`) refuses a household whose constraint cell has no sampling mass in the weight it samples by. A country that conditions its draw, as the UK geography-first draw will on the deprivation decile and the council-tax band, declares a fallback ladder instead, and the chooser picks each household's level before the draw.

- **Declarations.** `FallbackLevel(name, constraints, weight_by)` names the household inputs a level keeps as exact-match constraints, and says whether the level samples by the weight chosen for each household (`weight_by=True`) or by the default weight. `choose_fallback_levels(support, households, *, constraint_columns, weight_by, default_weight, levels)` takes the decoded support, a frame of household inputs, the support code column each input must match, the per-household rule `{"input": ..., "map": {code: weight column}}` (the draw's `weight_by` without its default) or `None`, the default weight column, and the ladder in order.
- **The rule.** Each household takes the first level whose inputs are present (every constraint the level keeps and, where it samples by the household's own weight, a code the rule maps) and whose cell, the support's areas matching the household on every kept constraint, has positive summed mass in the weight the household samples by there. It returns each household's level name, in row order. A draw that keeps a household's level's inputs, reads every other input as missing and samples each stage by the same rule then meets no empty cell. The chooser is vectorised, with one grouped mass table per level, read for the households no earlier level took.
- **Refusals.**
  - A household no level takes is refused with one fixed text that names no count, household or value.
  - A present input that is not a nonempty string without surrounding whitespace is refused, as the draw refuses it.
  - A declaration is refused where a level keeps an input `constraint_columns` does not map, a level samples by the household's own weight but no rule is given, an input maps to the area or to a column that is not a support code column, two inputs map to one column, a weight is not a support weight column, or two levels share a name.
- **No caller yet, and nothing moves.** The chooser names no country, and nothing calls it until the UK geography-first draw. No node binds the module: no transport kernel (the shared kernels New Zealand's graph runs on, the atomic geography and rules kernels among them), no UK graph kernel or gate battery phase, and no transport binding's source closure hashes it, and no US module imports it. So no node key moves.
- **Tests.** `tests/engine_free/shared/test_atomic_support_conditioning.py`, on invented supports only:
  - a household whose band has mass in its cell takes the first level, one whose cell has households but no banded mass takes the second, and a missing decile falls to the region-only levels;
  - a household no level takes is refused with the count-free text;
  - on 3,000 invented households the vectorised choice equals a per-row loop over the support's arrays, in any row order;
  - two Hypothesis properties on small invented supports and ladders: the chooser equals the per-row loop, and the shared draw itself finds mass at the chosen level and is refused at every earlier level whose inputs are present (and at every level, for a household the chooser refuses).
