A country-neutral fallback-level chooser for conditioned area draws: `FallbackLevel` and `choose_fallback_levels` in `microcosm.build.atomic_support_conditioning` (#931; shared, for Max's review). The shared draw (`assign_atomic`) refuses a household whose constraint cell has no sampling mass in the weight it samples by. A country that conditions its draw, as the UK geography-first draw will on the deprivation decile and the council-tax band, declares a fallback ladder instead, and the chooser picks each household's level before the draw.

- **Declarations.** `FallbackLevel(name, constraints, weight_by)` names the household inputs a level keeps as exact-match constraints, and says whether the level samples by the weight chosen for each household (`weight_by=True`) or by the default weight. `choose_fallback_levels(support, households, *, constraint_columns, weight_by, default_weight, levels)` takes the decoded support, a frame of household inputs, the support code column each input must match, the per-household rule `{"input": ..., "map": {code: weight column}}` (the draw's `weight_by` without its default) or `None`, the default weight column, and the ladder in order.
- **The rule.** Each household takes the first level whose inputs are present (every constraint the level keeps and, where it samples by the household's own weight, a code the rule maps) and whose cell, the support's areas matching the household on every kept constraint, has positive summed mass in the weight the household samples by there. It returns each household's level name, in row order. A draw that keeps a household's level's inputs, reads every other input as missing and samples each stage by the same rule then meets no empty cell. The chooser is vectorised, with one grouped mass table per level, read for the households no earlier level took.
- **Refusals.**
  - A household no level takes is refused with one fixed text that names no count, household or value.
  - A present input that is not a nonempty string without surrounding whitespace is refused, as the draw refuses it. A households frame that repeats an input column is refused with a fixed text.
  - A declaration is refused where a level keeps an input `constraint_columns` does not map, a level samples by the household's own weight but no rule is given, an input maps to the area or to a column that is not a support code column, two inputs map to one column, a weight is not a support weight column, two levels share a name, or the rule's input is also a key of `constraint_columns`. The draw samples by a present code's weight at every level, so a level could not keep such an input and sample by the default weight, nor drop it and keep the household's own weight.
- **No caller yet, and nothing moves.** The chooser names no country, and nothing calls it until the UK geography-first draw. (Later in #931 the spine's `atomic_area_assign` calls it: `931-spine-assigns-areas`.) No node binds the module: no transport kernel (the shared kernels New Zealand's graph runs on, the atomic geography and rules kernels among them), no UK graph kernel or gate battery phase, and no transport binding's source closure hashes it, and no US module imports it. So no node key moves.
- **Tests.** `tests/engine_free/shared/test_atomic_support_conditioning.py`, on invented supports only:
  - a household whose band has mass in its cell takes the first level, one whose cell has households but no banded mass takes the second, and a missing decile falls to the region-only levels, whether the frame holds it as None, NaN or pd.NA, in object, StringDtype, pandas' `str` or category columns;
  - two codes that share one weight column both read it, and of two identical levels the first is taken;
  - the default weight is the declared column, each input matches the support column `constraint_columns` names for it rather than a column of its own name, and a missing input never matches a support code spelled like a missing value;
  - a household no level takes, and a frame that repeats an input column, are refused with count-free texts;
  - on 3,000 invented households the vectorised choice equals a per-row loop over the support's arrays, and again under a shuffled row order;
  - two Hypothesis properties on small invented supports and ladders, whose rules may share a weight column between codes and whose ladders may repeat a level: the chooser equals the per-row loop, and the shared draw itself finds mass at the chosen level and is refused at every earlier level whose inputs are present (and at every level, for a household the chooser refuses).
