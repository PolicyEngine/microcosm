Builds now send their calibration diagnostics to the collector, at staging and at release (microcosm#1599). Builds and the Modal image require microcosm-emitter 0.15.0 or later instead of 0.14.0: 0.15.0 adds the Hugging Face module's setting that switches collector submissions on, collector provenance on a release publication, and a `skipped` collector receipt with an error code when the emitter refuses its collector settings. microcosm-build's `microcosm-emitter-interface` pin rises from `>=0.14.0,<1` to `>=0.15.0,<1` (the lock moves from 0.14.0 to 0.15.0, and `APPROVED_UV_LOCK_SHA256` is re-pinned for the new lock), and the installed-emitter job's pin rises to 0.15.0. Every emitter a build, the UK re-stage command or the release publication command starts has its collector submissions on (`telemetry_emitter.COLLECTOR_SUBMISSIONS`); the emitter's own default leaves them off, so switching them off again is a Microcosm change. A loopback collector given for telemetry (`development_collector_url`) takes the submissions too. UK staged bundles, which already name their build, are submitted after their Hugging Face commit. `microcosm-publish-release-build` names each build for the collector, country `UK` with licensed data for the UK national, dense and local-area releases and `US` without for the US releases, with the publication's own release and build, so the emitter submits the build's calibration diagnostics and manifests after the release commit under `releases/<release>/<build>`; the collector's calibration tree handler registers both countries' release repositories. Once a described bundle or publication has landed, the build or command waits up to ten minutes for the collector to accept the submissions, since an emitter that is closing starts no new submission; an attempt after the commit that fails ends the wait sooner, and a hand-over that has not landed is asked about once. A `skipped` receipt (`COLLECTOR_SETTINGS_REFUSED`, `COLLECTOR_FOLDER_TOO_LONG`, or Hugging Face's refusal), a rejected or failed submission, and submissions still queued when the wait ends are warnings, and never fail a staging or a publication; the publication command prints the collector receipt's `status` and `error_code` as `collector_submission`. The installed-emitter tests send the emitter's collector submissions to a closed loopback port.
