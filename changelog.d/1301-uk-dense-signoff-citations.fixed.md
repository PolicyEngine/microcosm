The dense sign-off drafter's free-text and login checks no longer let a figure through as a citation, and accept the citations they refused (microcosm#1301, answering the third review of microcosm#1307). Digits may now stand only in a citation of a repository on the tool's fixed `KNOWN_REPOSITORIES` list, matched in any case: an issue reference (`microcosm#N`, `chronicle#N`, `uk-data#N` or `PolicyEngine/<repo>#N`), a GitHub URL of an issue or pull request, optionally anchored on a comment or review (`#issuecomment-`, `#pullrequestreview-` or `#discussion_r` with the ten-digit id GitHub gives one), or a GitHub URL of a file, whose path may hold digits. A reference to a repository off the list, a count run into an anchor's id, a citation running into a word, and a citation right next to a noun a figure counts or belongs to (rows or households after it, a household or a weight before it) are refused, and an anchor now stands only in a URL. ISO dates must lie within 366 days of the day the tool runs, so a date-shaped figure far from it is refused. `--approved-by` accepts digits only in a login on the tool's `KNOWN_DIGIT_LOGINS` list, so login-shaped figures with one run of digits are refused while the reviewer's own login still passes. The runbook describes the new rule.
