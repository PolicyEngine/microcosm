State one contract for the solver's weight bound (`microcosm.calibrate.weight_bound`, docs/calibration-local-area-machinery.md): `max_weight_ratio` bounds each record against its weight on the frame the solve was given, never against a warm start, and a new frame is a new reference. Tests hold the solver to it. `calibrate` and `solve_constraint_system` take an opt-in `max_weight_reference`: the bound is then `max_weight_ratio` times a declared weight for each record (for example the mean weight, from `weight_bound_reference`), so a record that starts heavier gets no larger a bound. Without it the solve is unchanged byte for byte. `weight_bound_report` measures any weight vector against a reference, report-only. The calibrate parity pin is re-recorded for the edit to `solve.py` (microcosm#1729, microcosm#493).
