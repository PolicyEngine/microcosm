Remove Microcosm's copy of the Orrery projection: `microcosm.graph.orrery`, with its `python -m microcosm.graph.orrery` command, `microcosm.graph.orrery_evidence`, and the `orrery_document` and `orrery_json` exports of `microcosm.graph`. The collector builds every Orrery graph file with its own copy, whose contents match the deleted modules. UK builds no longer write `graph.orrery.json`, the publication inventory (`orrery.upload.json`), the receipt snapshot (`orrery.publication.json`), the manifest's `orrery_publication` field or the attempt evidence's `orrery-publication/` directory, and the emitter a build starts has no graph publication module. `tools/orrery-contract/`, which checked Microcosm's documents with Orrery's parser, and the engine-free CI job's Node setup go with them. Graphs are viewed through the run viewer from the collector.
