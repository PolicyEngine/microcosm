`tools/patch_us_acs_donor_columns.py` writes a patched copy of a published US national donor H5 for the County Files proof of concept's ACS staging (microcosm#922, plan microcosm#1647). It adds reviewed all-zero columns on the entity the US engine gives them (`strike_benefits`: no donor or ASEC pppub23–26 row has `OI_OFF` 12; `passive_partnership_s_corp_income`: the donor holds partnership and S-corp income as one combined `partnership_income`), refuses a column that is already present with any other value, keeps every other table, column, dtype and root attribute, and writes a receipt with both SHA-256 digests, the row counts, each added column with its reason, and the tool's commit. A restore step for the three ASEC work columns is reserved for a later commit. The published donor is read only, and no default changes. With `--input-release-manifest` it checks the input against the published donor's release manifest and records that build in the receipt. With `--release-manifest`, `--manifest-release` and `--manifest-build` it also writes a build-folder release manifest for the copy (in `policyengine/populace-us-staging` by default), so the ACS staging can take it as `--donor-release-manifest` and record the copy's build as `donor_release`, which the local-area release contract requires before publication.
