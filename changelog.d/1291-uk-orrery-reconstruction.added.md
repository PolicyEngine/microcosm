Add `python -m microcosm.build.uk_runtime.orrery_reconstruction`, which turns the output directory of a UK dense or national build from before #1144 into a declaration-only Orrery publication. It writes a new directory with the normal publication layout (`graph.schema.json`, `graph.orrery.json`, `orrery.upload.json`) and a summary report. The declaration comes from the build's recorded `graph.json` and the revision from its recorded code pin. Every input is checked against the digests the build recorded. The one exception is the candidate manifest digest that dense builds closed by #901's driver left in `build.json` beside the note that staging receipts follow: it is skipped and reported, and the manifest is checked against `sha256sums.txt` instead. Builds that already record Orrery evidence are refused, as is an output directory inside the build directory, which is only read. Nothing is uploaded.
