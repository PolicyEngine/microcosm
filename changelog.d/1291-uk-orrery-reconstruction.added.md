Add `python -m microcosm.build.uk_runtime.orrery_reconstruction`, which turns the output directory of a UK dense or national build from before #1144 into a declaration-only Orrery publication. It writes a new directory with the normal publication layout (`graph.schema.json`, `graph.orrery.json`, `orrery.upload.json`) and a summary report. The declaration comes from the build's recorded `graph.json` and the revision from its recorded code pin. Every input is checked against the digests the build recorded, builds that already record Orrery evidence are refused, and nothing is uploaded.
