The US national release tool builds and stops: it writes the dataset, its calibration weights, its diagnostics and the verdicts of the gates the build runs, plus `build_record.json`, and exits so the build can be evaluated. A new command, `tools/certify_us_national_build.py`, certifies a finished build: it runs the release's post-export checks on the written H5 and writes the manifests publication requires. Route A stops after the build too, and `route_a.sh --certify` certifies it (microcosm#1585, item 11). A build whose release gates fail still writes its H5 and record, so it can be evaluated or start a later build, but it cannot be certified, and no gate takes it as a reference.
