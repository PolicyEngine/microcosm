microcosm-fit's QRF forests build their leaf array in place. quantile-forest stores, for every tree, the training rows each leaf holds in one zero-padded int64 array (trees x nodes x outputs x width); version 1.4.2 builds one array per tree and then copies the list into the final array, which writes every padding byte and makes the whole padded array resident while both copies exist. `_fit_forest` now builds `_InPlaceLeafQRF`, a subclass that allocates the final array once and fills each tree's slice directly. The array is byte-identical to the library's, so every prediction and draw is unchanged; tests compare the two classes byte for byte on continuous, capped near-discrete, multi-output and weighted fits, and compare grid predictions and draws.

- quantile-forest is pinned to exactly 1.4.2, since the subclass replaces a private method, and `_InPlaceLeafQRF.fit` refuses any other installed release before growing a tree.
- `tools/measure_qrf_leaf_memory.py` fits one synthetic CPS-ORG-like wage forest or one capped near-discrete forest with each class in a fresh process and reports each fit's peak resident memory.
- Pickling or deep-copying a fitted forest still writes the full padded array, as before.
