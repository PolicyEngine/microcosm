`tools/sample_us_export_households.py` and `tools/probe_us_post_export.py` now record in `tool_source` the commit their own file was loaded from, with its sha256. They used to record the worktree's HEAD when they wrote the receipt or report, and in the first real run both named a commit made minutes after they started. Modules imported later (the editable microcosm packages, and the release tool and sampler the probe loads) come from whatever the worktree holds then. So each tool checks HEAD and the cleanliness of `tools/` and `packages/` again when it writes, and sets `moved_since_load` if either changed. The probe also records the sha256 of the release tool and sampler it ran. The sampler's `tools_dirty` becomes `dirty` and now covers `packages/` as well. Both schema versions are now 2. `docs/evidence/us-export-subsample-design/route-a-p005/` records that run: a p = 0.05 probe of the published Route A export against its full-size outputs.
