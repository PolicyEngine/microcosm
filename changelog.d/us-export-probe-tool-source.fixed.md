`tools/sample_us_export_households.py` and `tools/probe_us_post_export.py` record what they ran. They used to record the worktree's HEAD when they wrote the receipt or report, and in the first real run both named a commit made minutes after they started. Now each records `tool_source` before its heavy imports: its own bytes' sha256 (its tracebacks quote those bytes); HEAD; whether the working tree under `tools/` or `packages/` differs from HEAD's tree in any file's bytes or mode, with a sha256 of the differences; and an inventory of the installed distributions' names and versions, which never raises. Every watched file is read and its git object id recomputed, so the index cannot hide or invent a change: staging, a same-bytes rewrite, the assume-unchanged and skip-worktree bits, `core.filemode` and `core.ignorecase` change nothing, a case-only rename counts whether or not it is staged, and a file staged while the state is read is still seen. A file that changes while it is read is read again, and is recorded as unstable if it keeps changing; a path replaced by a FIFO or a link after its lstat is read again as what it is, and the open never blocks. Special files, unreadable files and nested repositories are recorded without being read as HEAD's bytes, and a submodule that is missing, replaced by a file, unidentified or at another commit counts as a difference. Only git plumbing runs, which never writes the index. When a tool writes, it reads the state again and sets `moved_since_load` if it changed. The probe also records the sha256 of the release tool and sampler it ran: the bytes it executed, compiled without its own future flags, for a tool it loads itself (the sampler records those same bytes as its own); the file at write time, said so, for one passed in. The sampler's `tools_dirty` becomes `dirty`; the probe report names the source of its process peak RSS (`ru_maxrss`); both schema versions are now 2. `docs/evidence/us-export-subsample-design/route-a-p005/` records that run, a p = 0.05 probe of the published Route A export against its full-size outputs, and a rerun of its smoke by the merged probe, which reproduces all 41 smoke rows exactly.
