UK full builds (dense and national) now record how a resumed attempt built on earlier ones. Each attempt's `request.json` names its Logbook build id and staging run id; the rowwise manifest gains an `execution` block (graph store, attempt directory, nodes reused from the store versus computed, and the earlier attempt directories on the same store with their ids); and the staging run gets the counts as a `graph_execution` stage event. The block sits outside the run parameters, so the candidate identity is unchanged.
