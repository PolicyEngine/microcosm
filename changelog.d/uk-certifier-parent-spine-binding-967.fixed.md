`tools/certify_uk_release_cut.py` and `compose_uk_release_certification` bind the spine supplied as stage evidence to the parent the calibration recorded (the build record's input posture and input pin, the signed diagnostics' build block): a spine that pins correctly on its own hash but is not that parent is refused before any family build-state gate reads its receipts, and the certification records the parent under `parent_spine`. The data contract's certification field set gains `parent_spine` (a sha256 digest), so a published certification always names the spine its release cut measured.
