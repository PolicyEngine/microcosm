`Frame.with_weights`, `Frame.place`, `Frame.select` and `load_frame_checkpoint` no longer deep-copy every table. Under pandas copy-on-write, frames from the three `Frame` operations share the memory of unchanged columns with their source, and the loader keeps the columns it decoded without a second copy. `calibrate` gains `return_frame=False`, which runs the same weight checks and returns the weights and diagnostics with `frame=None`. `Frame.adopt(tables, schema, weights, ...)` is now public, so other packages can build a frame that takes ownership of tables it decoded or built, as `load_frame_checkpoint` does: it validates like the constructor and, under copy-on-write, stores the given DataFrames without copying them. The caller must not write to those DataFrames afterwards, and `adopt` records no columns for `Frame.check_shared_columns`.
