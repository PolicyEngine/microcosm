`microcosm-build-uk --dataset-households` runs take the size stages' L2 penalties from the command line (microcosm#1124): `--selection-l2-lambda/--selection-l2-anchor/--selection-l2-basis` for the informed L0 search and `--refit-l2-lambda/--refit-l2-anchor/--refit-l2-basis` for the exact-count refit (chi-square basis; anchors `initial` and `uniform`). Each requires `--dataset-households`, is refused by the national role and, like every size flag, by release candidates; the release-candidate pre-flight fails on a recorded penalty. `UKGraphCalibrationConfig` carries them as `selection_l2`/`refit_l2`: the selection penalty joins the search, draw and refit node parameters, the refit penalty the refit node's alone, and the rotated holdout re-solves each fold under both. An off penalty adds no node parameter, no run parameter and no identity field, so default builds keep their node keys' parameters, manifests and checkpoint identities.
