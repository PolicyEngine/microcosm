The UK size refit now keeps its best epoch on the objective it minimizes (microcosm#1124). With an L2 penalty the shared solver used to return the closing state, because its best-iterate rule tracked the target loss alone. `calibrate` and `refit_l0_selection` gain `retain_best_objective`: with `l2_lambda > 0` on the plain Adam path (free mass, no L0) the solve returns the epoch with the lowest target loss plus the weighted penalty, recorded as `options["iterate_selection"] == "best_feasible_objective"`. It is off by default, so other solves are unchanged; the UK refit turns it on, since under the 100,000-household release its weights are the released weights.
