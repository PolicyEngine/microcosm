The US base stage checks the policyengine-us lock file (`engine_abi.lock.json`) once in the `--stage all` process instead of in every step process and QRF worker. The parent hands each step process a record of its check (lock file SHA-256, installed policyengine-us version and take-up and sources domain digest, in `MICROCOSM_ENGINE_ABI_LOCK_CHECK_RECORD`), which the step process passes on to its QRF workers; a child with its parent's record compares those three values instead of building two tax-benefit systems, and refuses to run when any differs. Processes without a record from their parent still run the full check. The QRF worker identity digest changes once, because its import trace now opens three fewer files.
