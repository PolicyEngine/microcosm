Ladder population targets are shared code for any country (microcosm#1728): `microcosm.build.ladder_population_targets` makes, for each declared geography level, the population rows (household size times the cell indicator), the cells no household supports, and the target specs with their calibration hierarchy, from declared names, record codes, geography ids and label lookups. The ACS local release declares its state and district levels in the `ladder_population` section of `us/local_target_construction.json`; the county rows stay with the county rung. The district module no longer imports the county module: the local tool picks the county rows for a county run. No target changes: `test_us_ladder_population.py` holds the shared code to verbatim copies of the replaced tool code, and the pinned bytes of `test_us_acs_local_surface_bytes.py` are unchanged.
