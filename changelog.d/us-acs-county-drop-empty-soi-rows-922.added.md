The ACS local release takes `--county-drop-empty-soi-rows` (microcosm#922). With it, a county IRS SOI row that is empty although the county has households (every household's measure, for example AGI, is 0, and the state row stores no zero) is dropped with a receipt in `county_surface.json` (`zero_measure_soi_rows_dropped`), the run identity and the reliability report, instead of refusing the run after the engine pass. Calibration grades such a county without the row, so the reliability report names each dropped row in its county cells (every member of a combined cell) and in a `zero_measure_soi_rows_dropped` column of `county_reliability.csv`; only a run with the flag has that key and column. A county without households is refused as before. The flag is off by default, and passing it is a reviewed decision; the refresh recipe repeats it. It is temporary for the County Files proof of concept (microcosm#1647; removal tracked in microcosm#1661): do not use it for the final County Files build, where a county whose row would be empty needs a real fix (more household support, or a declared cell with its own ruling), not a dropped target.
