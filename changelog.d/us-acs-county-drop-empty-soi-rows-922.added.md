The ACS local release takes `--county-drop-empty-soi-rows` (microcosm#922). With it, a county IRS SOI row that is empty although the county has households (every household's measure, for example AGI, is 0, and the state row stores no zero) is dropped with a receipt in `county_surface.json` (`zero_measure_soi_rows_dropped`), the run identity and the reliability report, instead of refusing the run after the engine pass. A county without households is refused as before. The flag is off by default, and passing it is a reviewed decision; the refresh recipe repeats it.
