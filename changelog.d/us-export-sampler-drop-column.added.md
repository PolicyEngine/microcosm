`tools/sample_us_export_households.py --drop-column NAME` (repeatable) leaves a stored column out of the subsample, so the current post-export stages can run on a published export that stores a column a later export contract refuses. It refuses a name no table stores, the household weight and the id and membership columns; the post-write check expects exactly those columns to be absent, and the receipt lists them under `output.dropped_columns`. The subsample now takes the name of the `--export` path as given rather than of the file a link resolves to (a Hugging Face cache snapshot's blob, named by its hash), and a subsample that would replace that link is refused.
