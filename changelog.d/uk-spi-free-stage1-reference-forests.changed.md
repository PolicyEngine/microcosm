The UK SPI income imputation (`impute_uk_spi_income_support`, build stage `hmrc_spi_income_spine`) frees each fitted QRF once it has finished drawing from it. The stage-1 model is freed before stage 2 is fitted. Each cross-fitting fold's reference model is freed in `cross_fit_transport` before the next fold is fitted. Stage 2 fits and draws one target at a time, through `RegimeGatedQRF.start_chain` and `fit_draw_next`, with the same per-person uniforms, so only one stage-2 target's forests are in memory at once. Before, the stage-1 model and every fold's reference model stayed referenced until the stage returned, and all of stage 2's targets were fitted before any was drawn. Each receipt the stage reports reads its values from a model before the model is freed: the weight kinds, the sign-classifier outcomes, the level offsets and the level-fit reports. The person table and the receipts are unchanged.
