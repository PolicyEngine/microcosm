Allow transport specs to declare pre-calibration rules stages with explicit outputs, optional derived outputs that stage nodes compute, recursive ancestry checks and holdout isolation for person and unit bindings. Only nodes in the ancestry of a calibration node are checked, so a stage binding's nodes after every calibration are unaffected. A stage's undeclared outputs are restricted by writer: each read follows the executor's writer chain through the reader's population-version lineage, where rewrites, masked owners and EXPAND claims pass earlier writers' values on and an EXPAND counts as a writer of its cells, so a column of the same name that another node owns in another version is not the stage's. A stage's node upstream of calibration may not be structural (CREATE, FILTER, EXPAND or REWEIGHT), because the ids, memberships, weights and strata a structural node writes reach later kernels without a column read. With stages listed, a malformed node or binding field the checks read refuses, naming the node or binding, instead of being read character by character; entitlement rows' selections are checked too, and the prepared engine-reference map is refused in any JSON spelling, with escapes decoded layer by layer in one linear pass each, and in selected resource data.
