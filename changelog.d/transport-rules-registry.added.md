Add explicit transport registry preparation with pinned Axiom bindings, one
multi-engine rules kernel, shared calibration and terminal kernels, and the
transport gate bindings. Engines use the persons-households-benefit-units
schema and nesting that the benefit-unit rule declares (the schema CREATE
builds). Engine-free adapters can exercise registry dispatch without
installing a country engine. Module hashes and tree digests bind the actual
RuleSpec bytes. Engine commit and wheel SHA-256 pins, and the RuleSpec commit
for exported trees, are format-checked caller declarations; installed engine
provenance is not checked.
