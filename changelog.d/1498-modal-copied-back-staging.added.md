`tools/stage_uk_rowwise_candidate.py --modal-receipt <receipt>` stages a UK run directory copied back from a Modal run with `modal volume get`. Before it starts an emitter, it checks that the receipt is of a stage that finished (`COMPLETED`, not stopped at its budget), that the directory is inside the run's copied-back state directory (`state/` beside the receipt's `receipts/` directory, or `--modal-state-root`), and that every output the manifest registers is in the receipt with the same SHA-256 and size; it refuses the directory otherwise. It then hands the bundle over with the re-stage command's existing code, so the records, retries and landed-bundle handling are those of a directory built on the workstation. The command now reports an output that does not match its manifest digest as an error message instead of a traceback.
