`tools/stage_uk_rowwise_candidate.py --modal-receipt <receipt>` stages a UK run directory copied back from a Modal run with `modal volume get`, for when a UK build is registered with the Modal runner. Before it reads any output, it checks that the receipt is of a stage that finished (`COMPLETED`, not stopped at its budget) and that the directory is inside the run's copied-back state directory (`state/` beside the receipt's `receipts/` directory, or `--modal-state-root`, both resolved). The receipt must list the build manifest and every output it registers; an output the stage never copied to the runs volume (`outputs_not_mirrored`) is named as such. While the build manifest still holds the build's own staged-dataset record it must have the receipt's SHA-256 and size, and every output must. The command refuses the directory otherwise, before it starts an emitter. It then hands the bundle over with the re-stage command's existing code, so the records, retries and landed-bundle handling are those of a directory built on the workstation. The command now reports a build manifest that is not valid JSON or not a JSON object, and an output that does not match its manifest digest, as an error message instead of a traceback.
