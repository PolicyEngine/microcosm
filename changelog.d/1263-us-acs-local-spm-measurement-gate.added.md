Add a release gate on SPM measurement composition to the US ACS local-area package stage (`microcosm.build.us_runtime.spm_measurement_gate`). It grades the calibrated H5 against the installed policyengine-us and refuses to package when any SPM unit that engine measures has no classified adult under spm-calculator's rule, when the stored `is_spm_independent_minor_role` is missing, null or not Boolean, or when the source SPM universe cannot be declared. An engine without universe scoping measures every unit; one that defines `spm_unit_spm_universe_status` measures the `INCLUDED` units of a release that declares them. The gate records aggregate counts only, split by source universe, and binds them to the packaged bytes. The publisher's contract now requires a passing `spm_measurement_composition` gate of every US local-area release, and no release directory is created until every package-stage gate has passed.
