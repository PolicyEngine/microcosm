Route A's build is one command: `route_a.sh` now dry-runs the release's gates on the fresh base as a stage of its own before the release starts (`ROUTE_A_DRY_RUN=1`, the default), so a certain failure stops the run in minutes. `route_a.sh --probe` probes an accepted build on a 5% household sample with certification's own post-export checks, and `route_a.sh --rebuild` sets an accepted build aside, keeping it on disk, to build the release again on the same base. A rerun to build refuses release settings other than the accepted build's, and the commit check requires the certification tool and parser on every run, whatever the tier. The US national build runbook has one command per step. The first run stops after the quick check (the base and the release-gate dry run, with the gate battery shadow on), which the operator reads with one command before the release starts, and one command collects a run's logs and records, without its data files, to send for diagnosis (review of #1681).
