A sized UK local release can now be scored for per-area representativeness (microcosm#1124 item G). `tools/score_uk_local_representativeness.py` reads a finished run directory and compares the shipped selection S with the dense solution D inside every constituency and local authority, on household size, tenure, the head's age band, the ONS household type and the income decile, alone and in six joints. Each comparison is a total variation distance beside the distance an ESS-sized draw from D would show by chance.

The per-area table goes to a private directory outside the repository. The summary keeps cross-area statistics only, over areas where S rests on ten or more distinct source households: median and 90th-percentile distances, the median distance-to-noise ratio, and how many areas exceed it. `uk_runtime.representativeness` carries the #1163 pool profile and variables unchanged, so the size-experiment harness can import them. Nothing in the build or its gates changes.
