The Modal stage runner gives the build it runs a collector token that only writes telemetry (microcosm#1470). With `--run`, `tools/modal_us_stage.py` first runs the launching machine's `microcosm-emitter telemetry-token` for the stage's class timeout plus 3,600 s, which exchanges the operator's Hugging Face login, and refuses to launch on any failing exit code, an unusable answer or a shorter lifetime. The token, its expiry and its origin reach the container in a Modal secret made for that launch, under the runner's own names (`MICROCOSM_MODAL_TELEMETRY_*`), attached with `with_options` together with any Hugging Face secret; the plan, its digest and its attempt budget are unchanged, and no receipt copies the token. `tool_environment` passes them to the build as `MICROCOSM_COLLECTOR_TOKEN`, `MICROCOSM_COLLECTOR_TOKEN_EXPIRES_AT` and `MICROCOSM_COLLECTOR_ORIGIN` only from that secret, removes those names from anywhere else, and sets `MICROCOSM_TELEMETRY_REQUIRED=1`. A plan may set that variable only to `0`, which asks for no token and runs the build without telemetry, and may set none of the token variables, nor `MICROCOSM_EMITTER_COMMAND`, so the build starts the emitter the runner verified. Before staging, the container refuses the attempt (finished, nothing charged) when the token is missing or incomplete, when the image's emitter does not answer `microcosm-emitter version` or reports no collector origin, when the token comes from another collector, or when it expires before the emitter may stop sending it: the budget's SIGKILL of the tool, 60 s after its SIGTERM at the class timeout less the stage's reserve, plus the emitter's 0.5 s to notice the build exited, its 15 s drain and its 30 s margin. Every refusal names the `0` opt-out. An image built before emitter 0.11.0 is refused at every launch until it is rebuilt (`MODAL_FORCE_BUILD=1`). The check reports the image emitter's collector origin and fails without one. The receipt's `runner.telemetry` records the token's expiry and origin, never its value; how many events the emitter left undelivered is not recorded yet, because how the runner learns that count without reading the emitter's event queue file waits on a decision. The image emitter's `version` now runs without credentials or the token. The registered tools do not start the emitter yet, so they send no telemetry until they do.
