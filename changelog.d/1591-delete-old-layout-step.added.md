`python -m microcosm.build.build_folder_switch delete-old-layout <repository>` deletes, in one commit, what the tagged layout left on a switched repository's `main`: every file under `releases/` outside a build folder (the release-folder contents each tagged build overwrote, and each release-per-build tag's `releases/<tag>/` folder) and the root dataset files (`.h5`, `.hdf5`, `.npz`). Build folders and `releases.json` are then the only layout. It keeps `releases.json`, every listed build folder, the other root files and every directory outside `releases/`. It refuses a repository that has not switched, a `latest*.json` file, and a build folder `releases.json` does not list, and it checks what remains with the emitter interface's repository and commit checks. Without `--write` it only prints what it would delete. Old builds stay readable at their tags.
