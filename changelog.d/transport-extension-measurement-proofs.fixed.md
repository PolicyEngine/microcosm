Composition now proves the measurement producer for each calibration node that a transport extension adds, such as a calibration-tier scenario's `calibrate.*` node. The declared proof (G8-r2c ruling R2C-1) reads only the declared graph's rows, so it never names those nodes, and the extension pass of `compose_transport_graph` never ran the compiled check. Now the extension pass runs it after the ancestry guard, as the skeleton pass does. For an extension's calibration node, exactly one compiled ancestor must declare the measurement, that ancestor must output every proof column, and no other ancestor may write one by output or EXPAND cell (R2C-15). The refusal names the node as an extension calibration node with no proved producer. Each skeleton calibration node keeps the declared comparison, which the extension pass now also runs on the extended graph.
