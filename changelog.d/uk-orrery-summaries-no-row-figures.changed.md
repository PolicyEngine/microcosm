The UK graph summaries that `--publish-orrery` submits no longer carry a target row's estimates and errors, the size summary's largest change in one row, or the gates' failure lines; a gate summary counts its failure lines instead. The build's private diagnostics and gate reports keep all of them. Since the build no longer withholds the rows resting on fewer than ten source households, the summaries could not tell those rows apart. The export now checks the summaries before it preserves anything for publication, and stops with the `unpublishable_summary` error code if one carries either. Without a preserved inventory, neither the build nor the emitter's retry command can submit them.
