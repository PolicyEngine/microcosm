US builds now forward calibration epochs to their staging bundle and hosted telemetry the way UK builds do: each solve's first and last epoch and every tenth epoch, with the stride growing so no run forwards more than 2,400 epochs on the stride beside those first and last epochs. Previously every epoch was forwarded. UK builds now also forward each solve's first epoch, one more row per solve, so the forwarded epochs fall at every boundary between solves and a dashboard that starts a new solve when the epoch falls no longer merges solves of ten or fewer epochs. The rule is defined once in `microcosm.build.calibration_epoch_telemetry` and both countries use it.
