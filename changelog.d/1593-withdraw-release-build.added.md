`microcosm-withdraw-release-build <repository> <release> <build>` withdraws a published build through the emitter's release writer, which sets its `withdrawn` flag in `releases.json` and leaves its folder as published. The writer refuses the release's current build and a build the record does not list, and never makes a withdrawn build current. The command refuses offline and while a `latest*.json` file exists, before it starts an emitter, and checks the emitter's write access first. A compatibility recertification or an annual projection is now refused when `releases.json` has withdrawn, or no longer lists, its build-folder parent or base build.
