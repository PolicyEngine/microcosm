Builds on a busy host no longer lose hosted telemetry because the local emitter service started slowly. `microcosm.build` now loads its public names on first use and reads the microcosm-frame version for its compatibility gate from distribution metadata, so the service no longer imports torch, pandas, numpy or the calibration stack, and the Hugging Face client loads only when the delivery worker first needs a token. On a host at load average 80–160 the service became ready in 0.4–0.8 s, down from 5.3–9.2 s. The build now waits up to 30 s for the service instead of 3 s, and the warning on giving up names the wait. The Modal environment and runner smoke probes star-import `microcosm.build`, so they still prove that the modelling stack imports.
