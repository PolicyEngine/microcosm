The UK firm export's layout is now a base table plus a registry of optional input groups (microcosm#1705). `uk_runtime/firm_table.py`'s `UK_FIRM_EXPORT_GROUPS` holds one `UKFirmExportGroup` per group, with the source columns that switch it on, the policyengine-uk and Microcosm-only columns it adds, the groups it extends, and how it fills and checks its columns; today they are `attributes` (the ONS region and legal status draws) and `paybill`, which extends it. `to_policyengine_uk_firm_table` emits the base and every group whose source columns the rows carry, and `validate_uk_firm_table` accepts the base and each valid set of groups (`UK_FIRM_TABLE_LAYOUTS`) and runs each present group's checks. `uk_firm_table_columns` and `uk_firm_export_groups` give a set of groups' layout and the groups a population carries. The named layouts (`UK_FIRM_TABLE_COLUMNS`, `UK_FIRM_EXTENDED_TABLE_COLUMNS`, `UK_FIRM_PAYBILL_TABLE_COLUMNS` and their policyengine-uk column constants) are now derived from the registry and unchanged, and a test pins that the same-seed test build exports the same columns, dtypes and values as before. The next input, such as profit or rateable value, is one registry entry.
