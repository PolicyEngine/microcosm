Every UK spine stage now hashes each first-party module its transform computes through, and each stage that calls the engine also each one the injected engine computes through for it. Every other UK graph kernel, except six held for a ruling, hashes each one its own code computes through, and each phase of a gate battery each one its own gates compute through (#931). `source_hash` hashes only the files it is given, so a node that called a function in a module its hash did not name replayed a stale cached output when that module changed.

- **The rule.** `test_uk_graph` derives what each stage's hash must name. It starts at the transform `graph_kernels` builds for the stage, and for a stage that calls the engine also at the engine the builds inject (see The engine), and follows every definition the code names into the module that defines it, to a fixed point. Annotations count, and so do re-exports, module attributes and `type` aliases, which read as assignments of their values. So do the names `microcosm.graph` exports lazily through its module `__getattr__`: the walk resolves each to the runtime module that defines it, from the table that `__getattr__` reads, and a test checks that every first-party module with a module `__getattr__` is listed. It then checks that the stage's hash covers every module it meets. Every definition is a value except for these:
  - six listed refusal-only checks, each with its reason, which a test checks write nothing and return nothing but None or their sole argument; two are kernel admission reads (see Kernels);
  - the stage's own declaration (`country_spec`, `source_manifest` and the spec engine), whose content the node key already hashes as the stage contract;
  - the listed core modules every node runs through (see Scope);
  - a single string, a function returning one column name, and a record class whose field types are of these kinds. Their module must be hashed by the stage or by a node upstream of it, whose key the stage's key chains on. Otherwise they are listed with a reason; two such names are listed.

  A collection of strings is a value, like a number, because it selects rows, columns or codes. A second test applies it to the UK's other graph kernels (see Kernels). Two more cover the transforms the production spine build installs itself; a transform installed inside the source adapter or the rung sampler must come from its stage's module or be a listed adapter, since neither hands the node what the wrapped transform declares. Control tests pin each way of naming a helper that the rule follows, a lazy export among them, each kind it skips, the core-module stop, each way a refusal-only check could write, and how the engine's second root picks and follows the methods a stage calls.

  - `microcosm.frame.rules`' `assert_rules_engine_country`, the fourth refusal-only check, which every stage that takes an engine calls first;

- **Gate batteries.** As María ruled on 9 Nov, each phase of a gate battery keys on what it computes through, and on nothing only another phase computes through.
