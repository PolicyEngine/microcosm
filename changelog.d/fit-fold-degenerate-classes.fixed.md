Two fold-level cases in microcosm-fit no longer leave values that are not probabilities or weights. Output for every other input is unchanged: a differential run of a fixed workload through the old and new code matched in every value.

- `out_of_fold_proba` gives each learner (`boosted`, `spline_logit`) the model's probabilities in a fold whose training rows hold a single class: certainty of that class, which the model and the training folds' shares already gave. No learner is fitted on such rows, and before, each learner's rows in that fold stayed at zero, which `categorical_scores` refuses as not a distribution (it used to score them at the log-loss floor). Every array the function returns now scores. A learner that no fold fitted, as when the target holds one class, still stays out of the result. Folds from `stratified_folds` after `can_deal_folds` reach this only when they deal whole groups into exactly two folds; the UK SPI stage deals households into five, and the UK APS stage deals rows.
- The class-balanced cross-fitted sign gate's weight helper refuses, by name, a class whose rows carry no weight, or weight whose total overflows. Before, it returned NaN weights (or zeros, for an overflow). A fit never reached it with such weights: the cross-fitted gate falls back to the in-sample gate (`in_sample_weightless_fold`) when some fold's training rows carry no weight for a class, before it balances anything.
