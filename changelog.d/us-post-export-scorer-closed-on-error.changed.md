US certification closes the post-export scorer when any error stops it during scoring, before the error leaves certification: when the reform-coverage smoke fails at the certified tier (or with an evidence-tier failure no owner matches), when a stage raises, or on a SIGTERM. A pooled scorer then kills the workers still running a unit (such as reform validation's first units, which start before the smoke's result is decided) instead of leaving them to run until the process exits, tells idle workers to exit, and removes the batch files. An ordinary error from closing is printed and the first error raised; an interrupt while closing is raised instead. A failed smoke that certification goes on past (the allow option, or an evidence failure with an owner) cancels nothing.
