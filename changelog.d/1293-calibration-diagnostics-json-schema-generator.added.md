`microcosm.diagnostics.calibration_diagnostics_v8_json_schema()` generates a Draft 2020-12 JSON Schema for calibration diagnostics schema 8 from the pydantic models, so consumers such as the collector can check `calibration_diagnostics.json` without importing them (microcosm#1293). Its description lists every rule the models enforce that the schema cannot express: cross-field reconciliations, finite numbers, non-blank text, strict integers and digest anchoring under Python's `re`. It also notes the one case where the schema is stricter than the models: literal values. Tests pin that every model validator is listed, that each listed rule has a document the schema accepts and the models refuse, and that valid and representative invalid documents are classified the same way by both.

`jsonschema`, already locked as a runtime dependency of `microcosm-build`, joins the `microcosm-diagnostics` dev group, so no new package enters the lock. The primary-QRF worker identity's approved `uv.lock` digest moves with the lock, as it does for every lock change.
