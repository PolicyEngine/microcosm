Builds need `microcosm-emitter` 0.11.9 or later, the newest release, and the Modal image installs `microcosm-emitter>=0.11.9` instead of `>=0.7.0`. Emitter releases before 0.10.0 send telemetry to the collector's Cloud Run address, which changes when the collector moves to another Google Cloud project; from 0.10.0 on, the default collector address is the collector's hostname, which stays the same. A build reads the installed release from `microcosm-emitter version` and does not start an older emitter (`MINIMUM_EMITTER_VERSION` was 0.6.0): it prints the installed and required versions with the upgrade command, `uv tool install --upgrade 'microcosm-emitter>=0.11.9'`, and continues without the emitter, as before. A test checks that the Modal image's floor equals that minimum. The `microcosm-emitter-interface` requirement (`>=0.7.0,<1`, locked at 0.7.0) is unchanged: emitter 0.11.9 accepts socket protocol version 1, which interface 0.7.0 sends.
