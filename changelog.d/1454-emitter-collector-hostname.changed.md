Builds need `microcosm-emitter` 0.11.9 or later, the newest release on 2026-11-02, and the Modal image installs `microcosm-emitter>=0.11.9` instead of `>=0.7.0`. Emitter releases before 0.10.0 send telemetry to the collector's Cloud Run address, which changes when the collector moves to another Google Cloud project; from 0.10.0 on, the default collector address is the collector's hostname, which stays the same. 0.10.0 would be enough for that; the newest release is required because practically no machine ran the separately installed emitter yet. A build reads the installed release from `microcosm-emitter version` and does not start an older emitter (`MINIMUM_EMITTER_VERSION` was 0.6.0). Its warning now says what the build loses: it continues without hosted telemetry or staging hand-overs and queues no Orrery graph publication, and a UK build given `--staging-read-back` fails at the read-back. The warning also gives the upgrade command, `uv tool install --upgrade 'microcosm-emitter>=0.11.9'`. A test checks that the Modal image's floor equals that minimum in one checkout; at a Modal launch the floor comes from the launching checkout and the minimum from the commit the plan pins. The `microcosm-emitter-interface` requirement (`>=0.7.0,<1`, locked at 0.7.0) is unchanged: emitter 0.11.9 accepts socket protocol version 1, which interface 0.7.0 sends.
