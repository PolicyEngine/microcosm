The dense build takes `--withhold-thin-rows-only` (María's ruling of 2026-10-26): it withholds the model figures of the rows resting on fewer than ten source households and skips the differencing check that withholds published rows beside them, in the calibrated gates, the diagnostics writer and the run's evidence summaries. On the dense surface that check's eigendecompositions ran for hours and then failed to converge, so the first build on policyengine-uk 2.151.0 produced no gate report. The switch is armed at run time by the build command and recorded on the calibrated gates node and in the build request, because the gate code it would otherwise change is shared with the source preflight, which keys the solve: a build with it reuses an earlier build's solve. It refuses `--publish-orrery`, and the national role refuses it.
