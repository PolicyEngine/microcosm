The US fiscal-refresh release tool no longer reruns policyengine-us over every household for the post-calibration December SSI candidate amounts and Medicaid eligibility. Each pre-calibration pass keeps its per-person values and a digest of each household's rows: IDs, membership, row order, and every column in the engine's static dependency graph of `uncapped_ssi` or `is_medicaid_eligible`. After calibration, households whose digest is unchanged take their earlier values, matched by person ID. The tool runs policyengine-us on the households whose inputs changed, and on one batch of unchanged households as a check; if that check disagrees, it runs every household again. Neither variable reads weights or a population-wide sum, so calibrated weights and L0's dropped households change no remaining value. No column written between the two SSI passes is an SSI input. Between the Medicaid passes, SNAP take-up and the other-health-insurance premium attribution change some households' inputs, and those households are rerun. The new country-neutral helper is `microcosm.build.household_pass_reuse`; `microcosm.build.us_runtime.household_pass_inputs` lists a policyengine-us pass's input columns.
