`microcosm-publish-release-build` and `microcosm-publish-release` again refuse a US national build whose own staging uploads never arrived. Since build and certification became two steps, the build manifest's `staging` block is the certification's, with the build's inside it under `staging.build`; the staging check now reads both, so a certification that staged or opted out no longer lets such a build through. `--allow-missing-staging` still lifts the check (microcosm#1585, item 11).
