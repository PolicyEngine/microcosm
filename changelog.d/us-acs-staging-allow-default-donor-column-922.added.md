The legacy ACS staging builder (`tools/_legacy/build_us_acs_multispine_base.py`) takes `--allow-default-donor-column COLUMN=REASON` (repeatable) for the County Files proof of concept's patched donor (microcosm#922). The dense-donor coverage gate then accepts that transfer-consumed column although every donor value equals the engine default; it still refuses an absent, unknown or not transfer-consumed column, and an allowance for a column with donor signal. The staging summary records each allowance and its reason (`allowed_default_donor_columns`, `orchestration.allow_default_donor_columns`) and adds the reviewed limitation `allowed_default_valued_donor_columns`, which the release carries forward. Modal staging plans never pass the flag. Without the flag, the gate, the outputs and the summary are unchanged.
