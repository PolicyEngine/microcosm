New Zealand's receipt contract now declares `"target_exceeds_eligible_mass": "assign_all_eligible"`, the opt-in rule added in #1734. When a take-up stratum's target exceeds the weighted mass left in its eligible pool, `nz.takeup.assign` and each variant's take-up node now assign everyone in that pool instead of refusing, and the receipt audit records the `shortfall`. The rule covers all four programs. Targets, eligibility and exclusion order do not change, and the calibration target rows still constrain the assigned flags. A new disclosure entry in the contract records the choice, and a declarations test pins the key inside `receipts`. Both receipt-contract params of the nine take-up nodes move, so the take-up nodes and their dependency descendants re-key: the central branch through `nz.package`, the entitlement bridge, the S0, S1, S2, S3 and S5 scenario rows, and the variant nodes that depend on each variant's take-up node. NZ's golden spec summary moves with `receipt_contract.json`. No shared source module changes.
