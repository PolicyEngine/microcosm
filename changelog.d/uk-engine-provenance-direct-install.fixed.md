A UK spine's engine provenance now records how policyengine-uk was installed when it isn't a release from an index: a git install's commit, an archive's hashes (an archive that records none is refused), or a directory. A build from an engine pull request's head no longer shares its engine identity with that version's release, and the UK country graph's default identity is hashed from the same provenance. A release's provenance and identity are unchanged.
