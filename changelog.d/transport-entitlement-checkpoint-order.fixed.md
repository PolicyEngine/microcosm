An entitlement document can now list its cell-diagnostics collector (`<bands id>.cell_diagnostics`) among its own checkpoints, for example ahead of the gate battery it feeds, so the collector's checkpoint manifest is written before that battery's checkpoint runs. Listing it used to stop composition with "Extension checkpoints must name distinct nodes.", because the extension always appended the collector as a final checkpoint. A document that does not list it keeps it as the final checkpoint.
