The Route A release driver now lives in `tools/route_a/` (driver, supervisor, sampler, static release-flag check, runbook) with every machine path in a git-ignored `route_a.env`; it previously existed only on the build machine. Its release stage stages telemetry by default: `with_hf_token.sh` fetches the Hugging Face token with `agent-secret` at exec time, so the token never reaches the stage config, argv or logs, and `ROUTE_A_STAGING=0` restores `--no-staging`. Every gate, the publisher's offline preflight and the `published: false` hand-off are unchanged; the published `4b57d15a2` release is unaffected.
