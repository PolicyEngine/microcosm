Remove the tagged publisher, `microcosm-publish-release` (`microcosm.data.publish_cli` and `tools/publish_release.sh`), which committed a release's files to Hugging Face directly, tagged them and wrote a `latest*.json` pointer file. It refused every repository that records its builds in `releases.json`, which the US, UK and BE release repositories all do, so every release now publishes each build into its own folder through the emitter with `microcosm-publish-release-build`. `publish_release`, `prepare_release` and `PreparedRelease` leave `microcosm.data.release`, `microcosm.data` no longer exports `publish_release`, and `microcosm.data.slack`, whose only caller was `publish_release`, is gone with the Slack webhook settings in `tools/release.env.example`. `publication_refusal`, which `microcosm-publish-release-build` runs, moves to `microcosm.data.release`. No command publishes a release that `publishes_to_build_folder` does not name (#1796).
