Keep the Modal stage runner's and the test suite's git commands out of an inherited repository (microcosm#1091). Git exports an absolute `GIT_DIR` to the hooks, `rebase --exec` commands and shell aliases it runs in a linked worktree, and `GIT_DIR` outranks `-C`. Under one, the runner's branch check fetched into the developer's repository (a promisor remote in its config, `refs/branch-check/tip` and promisor packs) and `_git` read that repository's `HEAD` as the clone's; under `GIT_WORK_TREE` or `GIT_QUARANTINE_PATH` a good branch came back unverified. Two test fixtures (the graph acceptance burndown's and the chronicle feed's) committed onto the checked-out branch and moved `origin/main`. `modal_us_stage_plan.git_environment` now drops the variables `git rev-parse --local-env-vars` lists, less the `git -c` carriers, plus `GIT_QUARANTINE_PATH`, from the runner's git commands; `tool_environment` withholds them from the stage tool and names them in the receipt's `runner.tool_env_removed`; and the root `conftest.py` removes them before any test runs (`test_support.git_isolation`).
