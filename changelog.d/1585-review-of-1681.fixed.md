Certification of a US national build at the certified tier now refuses a failed source-coverage gate before it writes either manifest, as it refuses a failed smoke, so such a build can still be certified as evidence. Every gate failure a certification finds is added to `certification_failures.json` beside the build record, and a build that passed its own release gates and then failed certification's is no reference for a later build, the release-gate preflight or the post-export probe until a certification ships it. A build writes `build_incomplete.json` before its H5 and removes it once its record is written, so an H5 that no record pins is no reference either. A failed build's H5 is a `--base-h5` only beside an `--export-input-mass-reference-h5`, since without one the export input-mass gate judges the export against its base. A standing evidence owner pattern now owns a failure line only from the line's start (microcosm#1585, item 11; review of #1681).
