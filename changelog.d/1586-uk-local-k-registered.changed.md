`publishes_to_build_folder` admits a UK local-area release (`microcosm-uk-2024-25-local-k<N>`) only when a dataset registry entry names it as its `release`. The registry names none today, so no local-area release publishes yet: the release validators refuse every layout of an unregistered name, and neither publisher takes one. The pull request that authorizes a `k`'s first publication adds its entry.
