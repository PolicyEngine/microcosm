The Route A driver (`tools/route_a/route_a.sh`) now says what a build from a newer main commit needs. Its feed and crosswalk blockers name the commit's own pinned feed digest and crosswalk digest, so a rerun's settings can copy them; the published run's defaults are unchanged. A fresh worktree syncs with `uv sync --python "$UV_SYNC_PYTHON"` (default `3.14`), because uv otherwise takes the newest installed CPython and the lock's torch wheels stop at 3.14. The sync drops `UV_FROZEN`, since uv refuses `--locked` beside `UV_FROZEN=1`. `--resolve` checks the `microcosm-emitter` the release would start against the commit's `minimum_emitter_version.json` with `tools/route_a/check_emitter.py`, which repeats the release's own checks (command lookup, a 15 s `version` call, the release floor and, when telemetry is required, protocol version 1). With `MICROCOSM_TELEMETRY_REQUIRED=1` a failed check is a blocker, otherwise a note. A missing packaged crosswalk is now a blocker that names no digest. The driver exports `MICROCOSM_TELEMETRY_REQUIRED` and `MICROCOSM_EMITTER_COMMAND` when the settings file sets them, so the stages see what `--resolve` checked. `tools/route_a/README.md` gains a section on building from main, and `docs/us-release-build-rule.md` records that the four September causes are answered on the `--base-h5` arm.
