The US fiscal-refresh release tool now parses the full SIPP 2023 person file once, checking its digest in that one read, and builds the financial-asset, SSI disability, Head Start, vehicle and voluntary-filing donor tables from that one read, instead of hashing and parsing the 3.73 GB file once per donor. The read tokenizes the file with `low_memory=True`, keeping only the columns the donors use, and then infers their types over each whole chunk, so it no longer holds the field positions of the file's thousands of unused columns for 100,000 rows at a time. The donor tables are unchanged; the vehicle and voluntary-filing donors refuse a column whose values their former `low_memory=True` parse could have converted differently. `read_sipp_december_person_rows` and one `build_sipp_2023_*_donor` function per donor replace the per-donor loaders that took a file path; `load_sipp_2023_ssi_disability_donor` remains for the ACS local-area build.
