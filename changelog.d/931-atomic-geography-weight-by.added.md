A sampling stage of the shared atomic-geography declaration can declare `weight_by` (`input`, `map`, `default`) in place of its one `weight` column: each household then samples by the weight column `map` names for its `input` code, or by `default` where the code is missing, and a code the map does not name is refused (#931). The UK geography-first draw needs it to weight a household's output area by the dwellings in its own council-tax band. Declarations without `weight_by`, New Zealand's and today's UK one among them, keep their canonical bytes, definition digest and draws; only the geography kernels' implementation hashes, and with them their cache keys, move. The graph builder adds the `weight_by` input to the assignment's household slice.
